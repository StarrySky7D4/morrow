# 设置保存、字体画布与控件视觉修复

日期：2026-09-24。应用仍为 0.1.9-test.54+58，内置工作台插件仍为 0.1.9-test.54.6。未提交、推送或发布。

## 修复结果

1. **停用工作台插件后可保存应用设置。** 私有 UI 设置上传取消对 guest 可用性的依赖，改由宿主仅授予固定设置记录的短期创建/编辑权限，仍通过核心事务持久化。数据校验、未知字段保留、原操作号、基准修订、持久提案和确认恢复保留。重试读取原提交，不把历史设置重新应用到当前值。公开 guest-evidence 保存路径和卡片写入权限不变；宿主保存不伪造插件执行证据。没有添加第二份配置文件或独立权威存储。
2. **字体设置页保留共享画布。** 原字体入口从外层 Navigator 推入透明页，使共享背景随旧路由退场；现在进入 `settingsNavigator` 下的 CanvasNavigation。字体页保持统一透明表面及标题栏，背景留在共同祖先中。
3. **深度表现打磨。** 六种实验/拟物风格的按钮原生填充形状与装饰边缘使用同一圆角。粗野主义改为透明中心之外的实心偏移侧影，结构线固定 1.8px，深度主要控制位移及淡入；按下使用内缘，移除嵌套彩色框。0% 不保留额外立体装饰。未改已有深度持久化字段。
4. **补齐开关和复选框过渡。** 开关图标先淡出、不可见时换形、再淡入；中途反向从当前图标/透明度继续。Material 使用稳定非空图标槽，无图标时透明，避免风格切换导致拇指半径瞬跳；因此无图标 M3 开关也采用图标槽的统一拇指尺寸。Apple 自适应仍使用原生外观。删除依据逻辑 value 估算位置的第二层拇指投影，移动、按压和拖动由一个原生 Switch 负责；拟物拇指通过原生颜色补足暗色对比。复选框保持一个原生 Checkbox，连续改变圆角、凹槽、光照、深度，并处理反向、减少动画、隐藏、高对比及 Apple 自适应。任务卡接入同一控件；插件/服务设置的原生 CheckboxListTile 通过可插值主题形状同样获得过渡。
