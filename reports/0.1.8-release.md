# Morrow 0.1.8+9 — 2026-09-09

This release adds animated sidebar/settings collapse, liquid glass panels with continuous material transitions, an independent liquid effect for all four canvases, and a redesigned Markdown idea editor with richer clipboard import.

The transparent canvas retains a fully transparent interior and edge highlights. Windows keeps native per-pixel transparency; it does not switch to Aero blur. Windows/Web panel refraction uses the documented matrix fallback. Office clipboard support preserves readable text, tables, available previews and original embedded files; it does not execute embedded objects or calculate formulas.
