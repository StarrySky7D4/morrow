# Morrow 0.1.9-test.53 · Windows 测试预览版

**重构阶段的测试预览版（Pre-release），仅提供 Windows x64 预构建，不是稳定版。** 应用版本为 `0.1.9-test.53+57`。

`test.1` 是 `0.1.x` 最后一个兼容原有数据类型的测试版。此后的 test 版本逐步推进重写，可能包含破坏性数据变更；架构与数据模型锚定后再发布 `0.2.0`。本版 Windows 默认使用独立 Rust 工作台，不自动导入 test.1 的旧资料。请先保留内容库及原保护文件的备份，再用副本体验；保护文件与当前 Windows 用户绑定，不能仅靠复制数据库完成跨账户迁移。

## 本次更新

- 插件系统集中到独立设置页，网络与文件 IO 设置另设页面；优化单列宽屏布局、标题栏、窄屏返回、组件与卡片的独立外观设置。
- 修复内容库打开错误被退出错误覆盖的问题，完善外观、卡片和语言偏好的保存与恢复；修正窗口圆角边缘和透明画布相关显示。
- 新增俄语、法语、德语、西班牙语、日语、韩语、葡萄牙语，与中文、英文共九种界面语言；切换语言保留编辑草稿、选区与查询状态。
- 优化设置页首次打开和启动衔接：窗口初始化与内容服务并行，工作台恢复后以短淡出移除加载界面，支持系统减少动画设置。
- 汇总开发线的 HTTP/HTTPS 请求、API 节点及 TLS 身份管理改进，包含受保护身份保存、选择、禁用及服务状态界面。网络操作仍受原有授权与范围限制。

## 下载与运行

完整解压 `morrow-0.1.9-test.53-rust-workbench-windows.zip` 后运行 `morrow_studio.exe`。请保留同目录 DLL、宿主程序、`plugins`、`data` 和许可文件，不要仅复制 EXE。本次不提供 Android 或 Web 构建。

发布附件包含 Windows 包、对应源码包及 SHA-256 校验清单。第一方代码、SDK、文档与素材采用 **AGPL-3.0-only**；历史 test.1 及更早版本与第三方依赖保留原许可。对应源码、依赖声明与构建脚本见本标签，包内 `SOURCE.txt` 指向相同源码快照。

## 已知边界

- 插件系统和完整 IO SDK 尚未冻结；跨重启 Unknown 结果核对、完整文件系统能力、三语言 IO SDK 与跨平台资格仍在推进。
- 新增译文尚未经母语使用者审校。
- 本机小型隔离库的工作台首帧中位数约 0.71 秒（Dart 入口起），加载遮盖约 0.83 秒完全移除；仍有个别约 18–22 ms 绘制峰值。这不是大内容库或所有设备的性能保证。
- 内置插件升级按包摘要重新核对批准状态；若已有库升级后提示只读，请在插件设置中检查并明确批准新包。不要删除内容库或原保护文件来绕过提示。
