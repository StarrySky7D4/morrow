The native host now stays transparent for all background modes; Flutter paints backgrounds inside the same rounded clip. Repeated appearance changes no longer reconfigure the native accent. An opaque fill inside that clip prevents background crossfades from briefly exposing the desktop; transparent mode still clears the canvas.
