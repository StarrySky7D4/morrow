# daemon 0.1.3+4 — 2026-09-09

- Removed square/round buttons; component radius 0–32 directly controls shape. Legacy `rounded: false` migrates to radius 0.
- Added independent Windows window radius 0–32. The runner sets the native window region, scales it by window DPI, and updates it on resize/DPI changes. Maximized windows clear the region; restore reapplies it. Flutter clipping and the visible outline use the same radius.
- Replaced `mist` with `custom`, including saved-theme migration. White/dark ignore custom grayscale/lightness; custom values survive preset changes. Custom controls are collapsed by default and reset to collapsed on theme selection.
- Moved the shared tips/lyrics footer outside page scrolling and page transitions, into a fixed glass dock above the viewport bottom inset.

Validation:

- Flutter analyze: no issues.
- Flutter test: 20 passed, including migration/content retention, preset isolation, independent native radius calls and persistence, fixed footer geometry at widths 1440/800/390, and existing music/lyrics/media/content regressions.
- Windows Release and Web release builds succeeded. Web retains the existing optional CupertinoIcons font warning.
- Windows release UI checked at 1280 × 720 and maximized: native radius 32/0/20, maximize/restore, collapsed/expanded custom controls, preset switch back to dark, fixed footer through settings and main-page scrolling. Left the window open, dark theme, component radius 32, window radius 20. Did not modify user content or media library.
