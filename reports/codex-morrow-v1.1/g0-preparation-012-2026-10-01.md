## 当前边界与下一决定

真实 CC Switch 仍在 `codex_config.rs` catalog 与 `proxy/media_sanitizer.rs` 直接调用原 Rust 函数。新 pure 包能经 Morrow 真实入口执行，不能替代这两个原产品调用点的 Wasm 资格。现有 qualification agent_host kit 缺 pure-transform family；Flutter private host channel 还含 library/credential 等可信动作，不能直接给第三方 client 使用。

下一架构选择仅在新增公开 transport/authentication、修改 Tauri product caller 前发生：

1. **推荐：统一 broker 的受认证 native-session 纯计算扩展。** Morrow 保持 contract owner；对外只允许固定无权限 handler/type、选定包 digest/revision、deadline/correlation，内部复用现有 Task/Runner。新增 source/auth wire 前报告，不暴露 Flutter private actions，不引入第二个 Store/HostRuntime，也不自动 fallback。
2. **备选：Tauri 内嵌受限纯 evaluator。** 必须另做 digest-bound admission/selection、预算/取消/生命周期和 fault 行为，改变统一 broker 边界；本轮没有实现或采用这个方案。

原 caller 的 Unknown policy（catalog 的 Unknown 映射与 media 的保留原 body）各自保留；guest failure 必须明确返回失败。catalog payload 只传模型/模态/目录子集，不能夹带 provider credential/auth config。

产品 native 编译前仍须核对现成 Windows 工具、frontendDist 及 build script 写路径；`CARGO_TARGET_DIR` 隔离不足以保护原 source/vendor，任何实际编译都必须用新的私有 source + vendor 工作副本。不能造假 frontendDist、跳过原 build 合同或放宽 offline/lock 来宣布 G0。

跨平台、完整 OS 非零短写完成、断电恢复、恶意同用户隔离、完整双产品 G0 与 SDK freeze 均未因本轮变为已验收。
