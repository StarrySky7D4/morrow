# 草稿交接恢复入口与工作台会话

日期：2026-09-24。基于 `codex/io-safety-refactor` 工作树 `e89f4ff`，应用版本继续为 `0.1.9-test.54+58`。承接已验收的持久交接私有协议，新增用户可操作的恢复入口。本轮未提交、推送或发布。

## 行为

工作台历史菜单新增“草稿交接恢复”。页面只读发现摘要；选中记录后展示完整原始文本、分类、阶段及固定附件的别名，不解析 Markdown 或打开附件原路径。长正文在独立受限视口内滚动，摘要使用惰性 Sliver 列表。状态包括待建立后继、子草稿已保存、父草稿已退休、取消及冲突。

建立后继、退休父草稿和取消都是独立确认动作，完成一个动作不会自动执行下一步。页面不会再次提交正式卡片。取消只作用于原提案身份，不重新分配操作号。

`EditorDraftHandoffCoordinator` 由 Studio 持有，离开页面不销毁；已发送请求、最后确认回执、当前选择和 Unknown 保留。刷新摘要不会清除 Unknown，核对其他记录也不能解除原操作的不确定状态；必须读取原身份并核对同一冻结提案才能继续。

每次动作先重新读取插件状态。建立后继还要求插件可用、已启用且已批准，并重新读取当前卡片，校验未删除及来源修订一致；随后核对完整提案、当前摘要和工作区写权限。宿主在实际动作中继续承担权威来源与状态校验，UI 预检不被当作消除竞态的授权。取消/退休处理宿主已有记录，不要求重新执行或重新安装业务插件，但仍检查当前写权限。

切库会失效旧 coordinator 并移除它拥有的恢复与确认路由，避免旧库原文残留在新工作区。移除的是明确保存的 Route，不使用泛化 pop 误关其他页面。迟到已确认回执仍留在原 coordinator，但不发布到新工作区。

九种现有语言各补 23 条界面文案，沿用外置语言目录及生成流程；未完成母语人工审校。

## 审查与测试

原生 GPT-6-sol/high 子代理承担 coordinator、翻译和只读审查，主代理负责主界面接入、测试、审核与构建；未使用 SubagentBridge。

审查发现并修复两点：动作前缺少当前插件/来源预检；切库失效操作后仍保留旧库恢复弹窗。新增预检失败和等待预检时切库测试，以及真实工作台确认期间切换 backend 后旧恢复页/确认框均消失、父草稿仍活动的断言。

最终组合 **41 项通过，无跳过**：

- 11 项 coordinator 测试：只读发现/核对、完整冻结提案与摘要变化、权限撤销、Unknown 原号核对、监听器触发切库、迟到回执、预检失败与重入边界。
- 6 项新对话框测试：只读查看、分步确认、Unknown 关闭后保留、请求在途关闭重开、确认期间切库、390px 德语 1.6 倍字号无溢出。
- 22 项已有编辑/附件恢复对话框测试。
- 2 项真实 Windows 宿主工作台测试：新增交接恢复完整流程及原附件恢复菜单兼容。

新的真实流程从宿主准备提案后关闭/重开，再通过 MorrowApp 的实际菜单发现、查看、关闭、重开、建立子草稿。退休确认期间切换 backend，验证旧路由均移除且父草稿未退休；回到原 backend，重新发现/核对并显式退休，核对 120,000 字节原始文本及业务修订未重复增加。使用隔离测试库，未改用户库。

原始加强用例一度超时：测试在 runAsync 内等待前序由 Widget 创建的宿主请求，而前序又等待 Flutter 假时间队列。现在等待原生响应期间持续推进真实 I/O 和 Flutter 微任务，并在泵循环外执行断言。修复后单项约 6 秒、最终组合约 8 秒通过；保留超时日志，不把它误报为应用运行卡顿或性能改善。

六个 Dart 目标静态分析无问题；`build_i18n.py --check` 检查 22 产物通过；`git diff --check` 通过。最终 Windows Release 构建退出码 0，入口为 `lib/main_rust.dart`。
