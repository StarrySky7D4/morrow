应用版本仍为 `0.1.9-test.54+58`。新增第一方 `workbench.cards.v2` 处理器与独立 Cap’n Proto 契约，插件包升至 `0.1.9-test.54.2`。没有修改冻结的 `tasks.capnp`、TaskId 引擎/codec、既有任务编辑/迁移投影或 V1 内容投影；本轮生成产物前逐一与上一轮摘要核对为未改动。旧插件归档保存在本地构建目录以便后续核验。

## 本轮行为

`Workbench::edit_card` 接通正文与标题、假设/结论、图标/颜色、附件、收藏、明确类别与阶段，以及删除/恢复。接口不能夹带一份文字待办或新任务列表覆盖已有 TaskId；类别和阶段也不会隐式全勾选。任务 ID、完成状态、来源、退休 ID 和不涉及的未知字段保留；编辑已有附件时还保留其嵌套未知字段。

附件按用户选定顺序从该卡片暂存项或源 Card 中取得，名称、字节数必须匹配。完整附件摘要与媒体类型进入事实记录，不能通过传一个其他卡片的资产 ID 借用附件。失败不清除暂存项；历史重试不会清除后来选择的附件。普通非编辑动作保留原外层附件，仍可导出原字节。

删除后新的普通操作和任务操作均被拒绝，仍可读取；恢复必须来自当前拥有者会话中的撤销记录，绑定删除修订且在 8 秒内。重开库不会创造新的撤销窗口。提交前后两次核对当前授权及实时恢复期限；已有精确操作的历史回执可在窗口结束后核对，但不能修改后来版本或重新开启撤销。

`cards-edit.v1` 固定完整源 Card、操作身份、选定包摘要、规范化请求、选定附件和原恢复事实。实际 Rust Wasm 的输出必须与冻结规则逐字节对应，再进入既有版本化核心事务。独立回放器新增该证据类型；旧证据继续交给原来的解析及重放规则。

## 尚未完成

这些入口已经位于真实 Rust Workbench 库，尚未接入私有客户端协议和 Flutter。迁移按钮继续保持未开放；混合版本查询、新版编辑器粘贴来源绑定、TaskId 界面与歧义处理仍需完成后共同验收。低层证据接口只用于可信宿主；纯推导不是执行证明，也不提供来源权威或新权限。

本轮未运行 Android/Web/其他原生平台验收、强制断电或完整窗口操作测试，未提交、推送或发布，不据此宣告 T31–T34 或 SDK 冻结完成。
