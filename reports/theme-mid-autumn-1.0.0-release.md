# 中秋 · 月满庭 1.0.0 · 独立主题插件预览

插件 ID：`org.morrow.theme.mid-autumn`。本主题单独发布，不预装进 Windows 客户端包；与 Morrow 测试预览客户端配套使用。

下载 `morrow-mid-autumn-1.0.0.morrowplugin`，在 Morrow 的插件管理中选择文件、确认导入，然后启用。Windows 建议使用 [0.1.9-test.56](https://github.com/StarrySky7D4/morrow/releases/tag/v0.1.9-test.56) 或更新的兼容版本；Web 使用支持主题导入的 [GitHub Pages 工作台](https://starrysky7d4.github.io/morrow/)。主题及其登记数据保存在设备侧。

- 月白、黛绿与桂金的浅深色配色，配套原创《月满庭》插画。
- 可叠加基础界面风格；默认保留自选玻璃、背景与组件材质，可选择由主题接管。
- 导入后默认停用；支持启用、停用和卸载，同时只启用一个主题。
- 不请求内容读写、IO 或网络权限；业务插件的启用与授权独立保留。
- 已安装此 1.0.0 包无需重新导入。该包保持既有字节，不用同版本覆盖不同内容。

包大小：661,049 字节。SHA-256：`b9c8dd591ef88e2d14be4ee7f4b402ff5d6563530618f71cbaf1e4d1b61d9751`。

附件提供插件、校验清单和对应的完整仓库源码 ZIP。插件源码及构建入口位于 `plugins/mid_autumn/`、`tool/build_mid_autumn_theme.ps1`。主题代码和素材采用 AGPL-3.0-only；第三方依赖保留原许可。

已通过真实 Windows 宿主导入、默认停用、启用、重启恢复、停用与卸载测试。具体使用与限制见[插件说明](../plugins/mid_autumn/README.md)。
