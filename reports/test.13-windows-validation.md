# test.13 独立材质与透明画布修正

日期：2026-09-12；应用 `0.1.9-test.13+22`。本轮未推送或发布 Release。

## 修正结果

- 移除统一组件覆盖，改为每个组件和每张内容卡片独立的设置页。入口为「空间外观 → 组件与卡片 · 独立设置」。按稳定 ID 保存，默认跟随主题，关闭开关保留本项参数，取消不提交。
- 模糊改由主窗口后方的独立合成画布承载。标题栏不在画布范围内，前景 Flutter 控件不作为模糊输入。主窗口逐像素透明模式保持不变；背景层跟随窗口位置、尺寸、圆角、显示与关闭。
- 染色不透明度只作用于画布染色层；0 完全不绘制染色。关闭模糊时销毁背景层，避免黑色合成表面残留。

## 验证

实际运行最终包中的程序，在测试程序自有红蓝色块场景上采样：

- 模糊 0、染色 0：原始红蓝色块透出。
- 模糊 12、染色 0：画布背景色块混合，没有黑底。
- 标题栏范围的采样不变；不透明前景白色保持原值。
- 模糊 12、染色 50%：仅背景染色改变。
- 恢复模糊 0、染色 0：所有采样恢复原值。

以上通过真实 Windows 合成像素检查，退出码 0。采样限定在自有测试窗口的固定区域，其他窗口遮挡会使检查拒绝；普通运行不启用验证场景。此结果证明本机测试条件下的效果，不代表其他 Windows 版本已实测。
