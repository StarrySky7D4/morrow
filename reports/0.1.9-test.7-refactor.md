# 0.1.9-test.7 重构记录

日期：2026-09-11。应用 `0.1.9-test.7+16`，Rust／独立 Dart 包 `0.1.9-test.7`；分支 codex/refactor-test.7，基于 test.6 的 bf18bdb。

本轮推进 M1-04／M2-01 的宿主连接分派与摘要读取权限，并补齐本阶段 Web 附件事务的中断矩阵。工作台和真实资料未切换，插件系统仍未完成；没有推送远端、发布 Release 或构建应用安装包。

## 已交付

- **宿主绑定连接**：HostRuntime 持有唯一 Store 与 HostPolicy，Connection 由宿主创建，不能从请求中自报身份、授权、时钟或数据库路径。固定请求副本用于解码和执行；跨连接、跨宿主和已断开的旧连接不能借用授权。
- **按能力区分读取与写入**：Rename 与 ReadSummary 独立授权到具体卡片及期限。读取前和投影交付前均检查授权，过期、撤权、排空和旧实例拒绝。无权限时不查询目标，存在／不存在目标均返回 Denied；摘要不含正文或附件名。已交付的字节不能追溯收回。
- **Cap’n Proto v3 双向契约**：请求新增摘要查询，响应包含请求关联 ID、契约摘要，以及提交回执／摘要／稳定错误枚举。64 位修订保持精确，CommitUnknown 不被当作确定未提交。运行期消息上限 64 KiB、摘要预览上限 16 KiB，超限不会作为裁剪记录保存。
- **浏览器接入同一分派器**：Worker 的标题修改与摘要读取请求／结果都为二进制。普通 Dart JS 增加 ReadSummaryCommand、RuntimeReply 和请求关联核对，改用 Uint8Array 承接 Worker 转移的 ArrayBuffer。旧 Dart 原生 FFI／Dart-Wasm 缓冲区接口仍仅做协议往返，尚未接入持久化分派。
- **附件恢复矩阵**：新增发布、移除各 7 个中断点，回收 3 个中断点；与既有 7 个重命名、4 个原件暂存一起，共 28 个实际 Worker 强制终止场景。新的实验 OPFS 池为 morrow-test7，64 个句柄容纳隔离场景，仍只允许一个持有者和一个 BrowserStore。

内部协议 v2 请求被明确拒绝，固定 Dart 绑定已重新生成；Protobuf 卡片容器仍为 1、实验数据库格式仍为 2。本次运行使用新实验命名空间，不能据此认定跨测试版迁移已经验收。

新增原生检查覆盖：只有写权限不能读、只有读权限不能写、目标存在性不经未授权查询泄露、跨连接／跨宿主拒绝、断连重连后旧连接失效、读取中授权到期、排空实例拒绝新读、提交回执去重后撤权阻断重试、旧协议／畸形请求不写入，以及响应长度／最大 UInt64。读取不会追加内容事务事件；审计读取事件等待 M4。

浏览器恢复逐点检查原子性：提交前操作结果不存在，提交后结果与附件列表一致；恢复后重试两次不重复递增修订。附件移除仍保留历史需要的原件，原件字节读回一致。回收中断后对象要么完整存在，要么已完整删除；再次执行回收不会重复删除。

测试以 Worker 终止触发中断，不执行正常 Rust 连接析构。OPFS 文件锁释放延迟只允许有限重开尝试，错误类型必须匹配，超时不算“正确拒绝”。这些证据不是浏览器进程崩溃、系统断电或不可信插件隔离的证明。
