# 0.1.9-test.6 重构记录

日期：2026-09-11。应用 `0.1.9-test.6+15`，Rust／独立 Dart 包 `0.1.9-test.6`；分支 codex/refactor-test.6，基于 test.5 的 727ceb1。

本轮推进 M1-03 普通 Web JavaScript 与 M2 浏览器持久化。主工作台仍使用既有保存路径，真实资料未读取或迁移；M2、插件系统和 0.2.0 尚未完成。没有发布安装包或推送远端。

## 已交付

1. **共享 Rust Store 的 OPFS 后端**：使用命名 VFS，独占连接、DELETE 回滚日志、FULL 同步；原生默认 WAL 保留。数据库格式仍为 2，创建／重命名／原件及事件使用同一 Rust 事务实现。无 OPFS 或池被占用会明确失败，不退回内存保存。同一实例第二个 BrowserStore 在打开文件前被拒绝。
2. **普通 Dart JavaScript 入口**：独立 web.dart 调用 Rust/Wasm 编解码器，绕开旧生成器的 UInt64 schema 字面量限制。Dart BigInt→JS BigInt→Rust u64，全程精确保留，不截断、不经 JSON 转换。旧客户端主入口仍不能直接 compile js；原生 FFI 和 Dart/Wasm 路径保留。
3. **真实浏览器事务验证**：Worker 用固定 Cap’n Proto 输入完成宿主授权的重命名，重复操作只提交一次，撤权／到期拒绝写入。事件容量耗尽不留下内容变化或操作结果。普通创建／附件／导出仍是可信第一方入口，不是完整插件授权接口。
4. **原件与演进往返**：100,000 字节原件暂存、摘要去重、字节导出和历史引用保留；原生生成含未知字段及 UInt64 最大值减一的卡片，Web 提交到最大值后导出，再由原生校验正文、标题、修订和未知字段。
5. **中断恢复**：7 个事务边界、4 个原件暂存边界，实际终止 Worker 并由新 Worker 打开恢复。提交前恢复旧内容，提交后保留新内容；再以同一操作重试两次，修订不重复递增。暂存中断不留下半个可引用对象，重试只留下一个原件。
6. **可复现资格脚本**：独立 Web 核心锁定依赖、生产／故障测试产物分开生成、普通 JS 编译、隔离 Chrome 临时目录与同源 OPFS、跨页面恢复及原生回读校验。

Worker 初始化已改为先注册收件处理，再等待模块就绪，避免首次请求落入异步加载空档。浏览器终止后的文件锁释放有短暂延迟；验证器只在明确的同步访问句柄占用错误下，最多等待 5 秒重新打开，每次终止失败 Worker。其他错误直接失败，不把超时算作“正确拒绝”。这仍是资格探针，完整产品恢复界面待接入。
