# Windows SDK 036 开发分支检查点（2026-10-16）

本次更新同步已经冻结、审核并装配的 Windows 原生执行链源码和开发进度。应用版本保持 `0.1.9-test.58+62`。这是开发分支更新，不是标签、Release、SDK 冻结或生产验收通过声明。

## 源码范围

- 同步 checked runner、原进程句柄、IO 线程、资源 owner 及原生退出／关闭观测的开发实现和限定回归。runner 的身份或退出不能替代业务子进程的证据。
- 补齐显式 v8 工厂的 Environment／SDK 构造链；旧 v7 入口继续严格校验版本、schema 和身份，不用默认值绕过失败。
- Windows setup 规则清单与 proof 使用一致的 COM Name；在后置检查前保存同次原始 proof，失败仍保持 Unknown，不重放旧操作。
- 保留启动、退出、读取线程和关闭债务的同次身份关联。035 的枚举分支编译失败已保留，036 显式补齐两个分支，没有增加兜底通配分支。
- 包含当前构建所需的开发测试支持源码及其许可证／来源说明。20 份原产品锁文件保持不变；私有测试验证锁不替代产品依赖资格。
