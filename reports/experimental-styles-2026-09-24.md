# 五种实验风格接入

日期：2026-09-24。基于开发工作树 `codex/io-safety-refactor` 的 `e89f4ff`。应用仍为 `0.1.9-test.54+58`；内置工作台插件升级为 `0.1.9-test.54.5`。本轮只更新本地源码和 Windows 预览，不提交、推送或发布 Release。

## 范围与设计参考

用户确认将五种方向全部加入实验选项。主设置仍默认收起风格列表，扁平仍是默认值，新拟态保留；五种新风格名称旁有实验性标记。

| 风格 | 本轮实现 | 参考 |
| --- | --- | --- |
| 纸感编辑 | 小圆角、轻薄边线、页片式浅硬阴影与简洁控件 | Morrow 原创探索 |
| 柔和黏土 | 较大圆角、内缘高光、柔和外部厚度、输入框内凹 | [Claymorphism](https://hype4.academy/tools/claymorphism-generator) |
| Fluent 雾面分层 | 克制的圆角与浅层阴影、轻量输入及控件边界 | [Fluent 2 Material](https://fluent2.microsoft.design/material) |
| 轻量粗野主义 | 明确描边、硬偏移阴影、较方正的滑轨与滑块 | [Neobrutalism components](https://www.neobrutalism.dev/) |
| 精密器物 | 细边框、凹陷输入与显示区、实体按钮及仪器式滑块 | [OB-4](https://teenage.engineering/products/ob-4) 的实体器物启发 |

这是项目自己的 Flutter 绘制实现，不包含第三方页面代码。Fluent 是视觉方向，不声称接入原生 Mica；器物风格也不是 OB-4 的官方界面组件。对话里的 HTML 探索稿不作为实际应用效果或性能证明。

本轮保留用户选定的字体、主题色及背景；不强制切换探索稿中的配色或字体。风格通过轮廓、层次和控件绘制表达。默认组件圆角随风格缩放，但用户设置为零仍为方角；组件显式自定义圆角保持原值。

## 接线与兼容性

- `VisualStyle` 增加五个明确值；未知值继续拒绝，缺省值仍为扁平。
- 卡片和面板的风格层只调整边缘、外阴影与圆角；保留玻璃模式、透明度、模糊、折射及组件跟随链。外阴影不填充透明面板中心。
- 共用控件绘制层接入按钮、输入、选中区域与下沉区域；Material 控件仍管理点击、输入、焦点、禁用和语义。开关、复选框、标签及滑块使用对应主题，随身听保留自有布局并采用风格滑块。
- 主设置与风格预览支持九种现有语言。展开后可选择，选择后收起，窄屏和大字号有专项测试。
- Rust 偏好校验同步接受新名称。现有 Protobuf/Cap'n Proto 文本字段保持不变，无存储 schema 升级；修改插件行为后提升 guest 包版本，避免同版本不同摘要。
- 迁移工具的旧 JSON 预检走相同校验；未知名称仍拒绝。旧程序/旧插件不认识新名称，**回退前应在新版切回扁平或新拟态并保存，再确认旧版自身的数据格式兼容范围**；这不是普遍降级兼容保证。
- 本轮独立构建暴露了宿主协议生成对同一 draft 包同时声明 extern 和生成的缺项。构建脚本先生成该包，再由其他协议引用，保留同一 Rust 类型，修复干净目录构建缺文件的问题。
