# Public historical validation records

These four JSON files are path-redacted derivatives of historical C13–C16 records. Local drive paths and path-bearing command text use `historical-local://cN/value-NNN` identifiers. They are not executable paths, raw original evidence, or new qualification of this published source tree. All original non-path fields, including exit codes, statuses, test names, counts, failures and evidence digests, are unchanged. Each JSON includes its original full hash and a hash for each replaced string. Original evidence remains separately retained; it is not included here.
