# Morrow 0.1.9-test.1

本次为 0.1.9 系列的首个预发布版本，应用版本为 `0.1.9-test.1+10`。

## 更新内容

- 新增主题色彩色罗盘，统一调整组件与控件颜色，支持实时预览、HEX 输入、取消还原、应用保存和恢复默认；入口按钮与现有调色罗盘保持一致。
- 窄屏下设置默认收起，打开后进入独立设置页；返回工作台时保留原内容、搜索与滚动位置，不改变宽屏侧栏偏好。
- 设置页进入与返回增加 320ms 淡出、淡入及轻微滑移动画，过渡中两页不重叠；支持系统返回、Esc 和减少动画设置。
- 移除设置页重复的关闭按钮，统一使用“返回工作台”。
- 补充全平台架构基线、前期调研和插件系统分阶段任务。后续使用 `0.1.9-test.x` 持续推进；当前不代表插件系统已建立或通过完整验收。

## 下载与使用

- Windows x64：下载 `morrow-0.1.9-test.1-windows-x64.zip`，完整解压后运行 `morrow_studio.exe`，保留同目录依赖。
- Web：下载 `morrow-0.1.9-test.1-web.zip`，将解压后的站点目录部署到 HTTP/HTTPS 服务；不建议直接双击 HTML 文件。
- Android ARM64：`morrow-0.1.9-test.1-android-arm64-debug.apk` 为调试签名测试包，最低 Android 7.0。应用显示版本为 `0.1.9-test.1-preview`，不属于正式签名发行包。
- `morrow-0.1.9-test.1-SHA256SUMS.txt` 提供三份下载包的 SHA-256 校验值。

## 验证范围

Windows 与 Web Release 构建、Android ARM64 debug 构建已完成。静态分析无问题，71 项单元／组件测试通过；三份包的完整性、版本与架构检查通过，APK v2 签名验证通过。本次新包未进行实机完整功能验收。
