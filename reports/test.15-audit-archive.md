# test.15 审计事务归档

日期：2026-09-12。独立 audit 模块升级到 `0.1.9-test.15`；Windows 应用仍是 test.14，本轮未推送或发布。

## 实现

新增 `audit/src/archive.rs`，提供原生 SQLite 事务式归档。签名段原始 Protobuf＋LZ4 容器与稳定事件索引一并提交，不重编码原始签名载荷。归档 API 只允许追加、查询与核验，更新／删除触发器用于防止意外修改。

幂等重试按日志、可信公钥、段号和已验签摘要核对；同一签名段重复提交返回已有回执。同段不同内容、缺段、错误前段摘要、跨段重复操作身份拒绝。每次写入事务重新读取链头，覆盖多个连接竞争场景。提交返回错误时使用 CommitUnknown，调用方不能推断回滚。

独立工具新增 `--archive DB` 只读路径，校验完整签名链、事件索引与原始载荷对应关系，以及可选的外部传入检查点。打开归档不从段内公钥建立信任。

- 两个连接重读链头、写锁竞争不修改数据、只读拒绝写入、原始未知字段保留、错误公钥／冲突／重复 ID、元数据损坏、非本应用数据库拒绝均通过。
