# 主工作台混合格式与 TaskId 接线

本轮将已验证的 V1/V2 私有接口接入主工作台，而非仅新增独立客户端 API。应用仍为 `0.1.9-test.54+58`，第一方包仍为 `0.1.9-test.54.3`；未提交、推送或发布。真实测试只操作临时资料库，未迁移用户资料。

## 当前实现

- `RustStudioStorage.open` 和编辑关闭后的刷新使用混合扫描；主查询使用版本化查询。正常启动不再因资料库含 V2 卡片而调用旧 V1 解码路径。无业务插件时仍可读取已有内容。
- V2 通过 `Idea.versioned` 持有完整类型化记录与展示投影，旧 `todos/completed` 保持空。`Idea.toJson` 明确拒绝 V2；原生偏好暂存仅保留进程内 `workspaceIdeas`，交给宿主的偏好不包含第二份卡片正文。普通本地/V1 存储保持原路径。
- 项目卡展示前 3 个 TaskId 条目与三态计数；详情页可逐 ID 确认同名歧义、添加、改名、重排、移除、单独修改阶段，或明确确认批量完成并设置阶段。阶段只列当前类别允许的值，九语言显示本地化标签。
- 普通字段和附件通过捕获编辑桥接保存，不把 V2 送进旧待办编辑。打开前绑定预期源修订，拒绝打开过程中已变化的基线。既有附件精确匹配，新附件逐项暂存后才提交；重试保留同一请求。显示回读可以前进到更高的当前修订。
- 分类、收藏、删除和恢复走类型化卡片接口。UI 持有原操作、原源修订及命令；未知结果只重试原意图，不允许替换为新动作。已提交但附件导出/回读失败单独报告。
- 删除确认成功（含原操作重试）统一提供撤销。界面以首次发送前启动的 Stopwatch 扣除耗时，提供保守的剩余窗口，不将宿主单调时钟的 deletedAt 当作 UTC，也不在迟到确认后重新给予完整 8 秒。
- 卡片带进程内内容所有者引用；跨资料库的旧页面回调和不同宿主的同 ID/同修订卡片在发送前拒绝。迟到回复继续受当前后端身份与修订保护。
- 本地未发送的非法草稿采用专用异常，允许修改后提交；例如超 2048 UTF-8 字节的待办不进入宿主或未确认操作队列。通用宿主错误不被误认为未提交。

## 附件与布局

附件长度以 BigInt 保留完整 u64；兼容 int getter 超出安全范围时明确拒绝，旧 JSON 输出不变，精确模式使用十进制 exactSize。展示不将大数截断。

缓存不假定附件 ID 等于内容摘要。仅在已确认、相邻修订且操作保证继承原附件时复用；其他变化重新导出，并同时比较新导出及旧缓存文件的实际 SHA。真实测试证明连续任务切换不会增加副本，未知修订下被改写的预览会恢复为真实原件。关闭时只清理本会话记录的预览文件，不删除用户导出。进程异常退出后的遗留缓存预算/回收仍需单独完善。

TaskId 面板改为适合窄容器的纵向布局，操作按钮允许换行；测试覆盖 280px/2 倍字体及 390px/1.3 倍字体。新版文案共 15 条、九语言，生成与占位符校验通过，尚未经过母语使用者审校。

## 下一阶段仍需完成

1. **可靠的宿主未提交分类**：通用 host error 仍无法证明没有效果。必须在提交边界之前、且按 Card+operation 查询明确 Absent 时才能返回专用 NoCommit；一旦进入提交、撤权、回复编码或传输阶段仍按结果未知/已提交处理。当前未覆盖的确定性宿主拒绝可能保留待重试状态；不得解析错误字符串来自动释放它。
2. **正式迁移入口**：主 UI 已能显示和操作既有 V2，但还未提供固定基线迁移确认按钮；真实原生窗口、更多规模与失败恢复门槛仍需完成。不得自动迁移用户资料。
3. **跨重启编辑恢复**：本会话内冻结意图不等于持久恢复材料。未完成编辑、更新草稿和未确认提交需要各自可恢复；重启不得自动外发新操作。
4. 完整 ErrorEnvelope、语言/字体保存恢复、远端 Unknown 与各平台验收仍开放。SDK 不冻结，审查总目标保持未完成。
