# Web 主题插件支持与验收

## 本次范围

仅开放符合现有 `theme.describe` 类型协议、无业务权限、无 IO/服务声明、无依赖的主题包。完整通用插件方案保留为后续工作；本次不增加浏览器文件系统授权、网络、凭据或服务运行能力。

改动在 `codex/web-theme-plugins` 隔离工作区整合。主工作区其他未提交的菜单、提示、卡片编辑等功能未纳入发布，也未覆盖。

## 实现

- 新增 `ThemePackageImportControl`，Web 使用选中文件的有界不可变快照，检查和确认复用同一个 Blob；Windows 仍使用原路径接口。
- Worker 接收小型控制帧和独立 Blob，Rust 以最多 64 KiB 分块读取。包上限沿用 `MAX_PACKAGE_BYTES = 4,276,930`；普通请求仍限 128 KiB。
- 宿主校验归档、主题协议、权限及依赖。主题专用通道和原有 Web 字节导入入口均执行限制；确认绑定包摘要和登记修订号。
- 安装、批准、启停、升级和卸载复用现有 OPFS 登记库。新导入默认停用；同版本同摘要可重复检查，过期修订和摘要不匹配拒绝。
- 通用主题控制器加载配色、描述和分块插画，校验长度、SHA-256、声明尺寸和实际解码尺寸。修复 Flutter Web 不支持 `ImageDescriptor.width/height` 的问题：先读取编码图片尺寸，再核对解码帧尺寸。
- 同一资料库只启用一个主题，切换时保留业务插件批准。主题覆盖属于显示层；停用/卸载恢复原有背景、音乐和设置。
- 错误文件返回普通失败回执，不关闭 Worker。导入回执未确认时不自动重放或启用，重开读取设备登记并提示用户核对。
- 包、登记、启用状态及主题偏好留在设备侧。GitHub Pages 仅分发静态程序。

## 验证

- 宿主：原始大包、默认停用、摘要绑定、过期预览、重复导入、重开恢复、损坏/超限/非主题包及带权限/IO/依赖的伪主题拒绝。
- 登记与运行时：主题互斥原子切换、旧主题撤销、业务插件启用与批准不变。
- Windows：真实原始主题路径导入、启用、插画、关闭重开、停用和卸载；内置工作台摘要/批准/启用状态不变，业务歌词解析可用。
- Flutter：主题切换、失效描述/插画/尺寸/修订、设置保存失败、窄屏、浅深色、编辑草稿和原外观保留。
- 真实浏览器：实际文件选择、检查/取消、错误文件拒绝、提交后丢失回执、重开后保持停用、明确启用、浅深色截图、刷新与关闭标签后新开恢复、停用/卸载，以及继续保存内容和媒体。
- 现有 Pages 内容、离线编辑、旧资料、孤立数据保护和图片/视频/音乐保存场景继续验收。
- 发布门禁新增主题宿主/界面回归及 CPU 4 倍限速主题浏览器验收。自动化等待实际 Worker 回执与界面状态，避免用固定短暂停代替确认。
