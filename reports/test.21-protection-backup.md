# test.21：运行中备份保护文件

日期：2026-09-12。应用 `0.1.9-test.21+26`，审计／宿主 test.21；核心 test.19，Rust 工作台插件 test.13，SDK／执行后端 test.11。当前为本地开发版，未推送、打标签或发布。

## 已实现行为

Windows 设置新增独立「内容保护」玻璃卡片与「备份保护文件」按钮，沿用设置按钮、主题颜色及圆角；同时进入组件独立材质列表。保存对话框建议带时间的文件名；取消不写入，处理中禁用重复操作，成功、失败与结果待核对分别提示。

可信 Session 使用原会话锁与固定身份核验内容库及当前保护文件，只导出一次读取并验证过的原受保护容器。临时文件写入并同步后禁止覆盖地发布，再重新读取最终文件核对字节和身份。不会生成新签名身份，不输出明文私钥，不修改内容库或待封存队列。保护文件损坏、丢失或在会话期间被替换成另一身份时拒绝备份。

备份通过私有 Cap’n Proto 的 `backupProtection` 命令传递用户选择的目标路径，保护文件字节不通过响应交给 Flutter 或插件。宿主合同摘要及 Dart 绑定同步更新。此能力与业务插件独立，插件缺席时仍可备份，原插件协议没有新增权限。

已有目标不覆盖；保存位置错误有对应提示。发布后不能确认结果时要求核对现有文件，不声称备份文件不存在。备份只供原系统账户保护条件下恢复原保护文件，不包含卡片或附件，也不是完整内容库备份。
