## 功能与实现

- Rust 文字工坊：Unicode 文本编辑、空白整理、合并段落、回填／清空、字符与行数统计。
- C 单位换算：温度／长度、正反向、普通十进制解析、示例与重置；非法数值展示提示并允许继续修改。
- C++ 清单助手：前 8 项任务生成、勾选、完成比例、预览过滤、保留勾选的排序、清除已完成与恢复示例。
- Flutter 按工具区分主题色、图标与结果布局，增加淡入位移、复制和重新开始；共享控件为浮动标签增加滚动留白，工作区按工具需要伸展。
- 全部业务计算在实际 Wasm 模块内完成。宿主校验 Session 后提供前一份可信 Document 与 Event，插件返回的新快照再次解码校验。输入串行派发；动作等待已确认视图，避免排序前的旧控件指向不同任务。
- C SDK 增加有所有权的文档解码／节点读取／释放接口；新增接口支持非对齐输入缓冲区，不改变核心 UI schema。原来的三语言最小 UI 示例保留。
