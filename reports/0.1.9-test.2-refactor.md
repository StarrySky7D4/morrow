# 0.1.9-test.2 重构记录

日期：2026-09-11。应用版本 `0.1.9-test.2+11`，核心 crate 版本 `0.1.9-test.2`。本轮为 M0／M1 部分交付，不代表完整重构、M2 提交闭环或插件系统完成。

## 版本与实施边界

`0.1.9-test.1` 是 `0.1.x` 最后一个兼容现有数据类型的测试版。后续使用 `0.1.9-test.x` 推进大规模重写，可能包含破坏性数据变更；核心架构、数据模型锚定，插件系统及声明支持的平台通过验收后发布 `0.2.0`。

本次附件与 `docs/ARCHITECTURE_BASELINE.md` 的 SHA-256 完全相同：`b70f7802aa6c0a956cc35c1635f62a3626c1d01d21e97cb8988ec6cd6d692cb1`。没有扩大首版架构范围。

本轮没有切换旧工作台保存路径、没有读取真实用户资料、没有自动迁移。独立 Rust 核心只执行内存编辑提案和只读容器验证，不与 Dart 同时维护一份正式数据。随包模块、动态插件、沙箱与权限系统仍明确区分。

## 恢复基线

test.1 提交：`a3c17668f05a7545ac0f01d15efea6494955a601`。本地 `build/refactor-baseline-test.1/` 保存：

- `source.bundle`：`git bundle verify` 通过；实际克隆到测试目录、确认恢复 HEAD 并通过 `git fsck --full`。
- `source.zip`：191 个文件逐项与 Git blob 原字节一致。归档显式关闭 `core.autocrlf`，避免 Windows 换行转换改变基线原字节。
- `verification.txt`：记录源码归档和原 test.1 三端分发包 SHA-256；三个旧包摘要全部匹配原 BUILD.json。

这些是源码与合成数据恢复证据，不等于真实用户资料备份验收。恢复文件在忽略的 build 目录内；兼容源码仍由 test.1 标签与 `0.1.x` 分支保存。工作分支为 `codex/refactor-test.2`。
