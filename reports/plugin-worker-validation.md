## 并发与故障检查

| 场景 | 已观察结果 |
| --- | --- |
| 阻塞首个宿主调用，填满队列 | 调用线程可继续提交／查询，容量包含正在执行任务，超额 Busy |
| 阻塞期间 stop | 先撤权再取消；未通过最终授权的重命名未提交，排队任务零宿主调用；实际退出前维持 Stopping |
| 独立数据库连接先观察到提交，再 stop | 已有修订 2 保留；后续响应取消，未把停止报告为回滚 |
| 正常 drain | 不再接收新任务，已接收任务完成，连接退休，线程结束后取回核心 |
| 缩短排空期限 | 迟到回复 Deadline，过期排队任务零宿主调用；期限不是阻塞系统调用的强制中断 |
| 单任务取消／丢弃句柄 | 该排队任务取消，其他任务继续；每个结果只消费一次 |
| 独立连接观察到提交后注入宿主 panic | 工作线程失败，结果 Unavailable；重新打开数据库仍有已提交回执 |
| 空闲停止与非法选项 | 无任务启动，关闭完成；零超时、过大超时和容量拒绝 |
