# 风格深度设置

日期：2026-09-24。开发工作树 `codex/io-safety-refactor`，基线 `e89f4ff`。应用版本仍为 `0.1.9-test.54+58`；内置工作台插件因行为与私有协议变化提升到 `0.1.9-test.54.6`。

## 使用方式与范围

主设置的风格选择下方新增「立体深度」滑块，仅在新拟态、纸感、黏土、Fluent、粗野主义和器物六种支持深度的风格中显示。范围 0–200%，100% 保留原外观，提供恢复 100% 按钮。切回扁平时隐藏滑块并保留已选值。

深度放大或缩小原有浮起/凹陷强度，不反转控件状态。影响卡片外阴影、共用表面/按钮、凹陷输入、新拟态开关/复选框/标签及风格化滑块的立体绘制；保留玻璃透明度、模糊、边界轮廓、圆角和可访问性提示。主要通过偏移、边缘深度和强度变化实现，模糊核不随参数扩大。

组件独立设置新增相同滑块。开启自定义且没有跟随其他组件时可修改；为空时继承主题深度，点击「跟随主题」清除局部覆盖。已有多叉跟随链解析目标组件的有效深度，解除跟随后自身参数仍保留；成环拒绝规则不变。组件深度用于该组件表面，内部明确使用主主题 Palette 的控件继续遵循主主题。

## 保存与迁移

Dart SurfaceSettings/ComponentMaterial、私有 Cap’n Proto、Rust 校验与持久 Protobuf、旧 JSON 预检及迁移路径同时接入 styleDepth。全局缺省为 1；Protobuf optional 与组件 hasStyleDepth 区分「未设置」和「明确为 0」。旧库缺少字段时保留 100% 外观，组件未设置时继承。非有限值和超出 0–2 的值在导入/宿主写入边界被拒绝。

私有 studio 契约摘要与 Dart 绑定同步生成。新程序须搭配本轮宿主和插件；本轮不声称旧程序可无损编辑新参数，也没有修改公共 SDK 版本。九种界面语言新增相关文案。
