# Morrow 0.1.9-test.56 · Windows 测试预览版

应用版本 `0.1.9-test.56+60`。本版为 Windows x64 测试预览（Pre-release），不是稳定版。

## 本版变化

- 增加卡片、小组件、任务和音乐列表的右键操作，支持卡片自定义排序及长按拖拽；拖拽后立即更新，保存失败时回滚。
- tips 默认文本、此刻小事及卡片内 tips 使用逐条编辑界面，支持增删和排序。
- 筛选结果原位更新，关闭未修改的编辑器、修改外观设置不再无条件重载内容列表。
- 修复宽屏双列瀑布流在重排、筛选、单双列切换后的错列与空洞；保持卡片状态和按需加载。
- 优化窗口关闭和内容服务收尾，等待已提交写入完成；修复原生运行器销毁顺序导致的退出卡顿与异常。
- 支持独立主题插件，主题与基础风格可以叠加；保留主题接管材质时的 tips 文本编辑入口。
- 合并 Web 本地主题导入、设备侧恢复和浏览器验收流程更新。Web 页面仍由 GitHub Pages 单独部署，本 Release 附件提供 Windows 客户端。

## 下载与使用

完整解压 `morrow-0.1.9-test.56-rust-workbench-windows.zip`，运行 `morrow_studio.exe`，保留 DLL、宿主、`data`、`plugins` 和许可目录。附件同时提供对应源码 ZIP 和 SHA-256 校验清单，包内 `SOURCE.txt` 标明源码与构建提交。

中秋主题没有预装在 Windows 包内，请从[独立主题发布页](https://github.com/StarrySky7D4/morrow/releases/tag/theme-mid-autumn-v1.0.0)下载 `.morrowplugin`，在插件管理中导入并启用。已安装相同 1.0.0 包的用户无需重复导入。

延续重构测试版的兼容边界：`test.1` 是原数据类型的最后兼容测试版；升级前保留资料库和原保护文件。保护文件与 Windows 用户绑定，仅复制数据库不等于跨账户迁移。本包保留此前已验证的工作台 guest 字节，避免同版本插件包被不同构建字节替换；不自动覆盖旧资料库。

## 验证

- 合并后 60 项 Flutter 回归通过：瀑布流坐标、状态保持、排序、tips、主题切换、组件配色及筛选更新。
- 使用最终构建的 Rust 宿主与兼容工作台包，4 项原生集成通过：主题导入/启停/重启/卸载、业务插件授权、内容与偏好持久化、保护文件恢复。
- 瀑布流修复的 Windows 实机 17 项回归通过，详见[布局验收](masonry-layout-2026-09-25.md)。
- 最终 Windows Release 重新编译，EXE 文件和产品版本均为 `0.1.9-test.56+60`。
- 最终完整目录的新库自检、上一轮测试库副本启动均以退出码 0 通过。真实 WM_CLOSE 验收中内容服务约 94 ms、应用约 139 ms 退出，无服务残留；这是隐藏测试进程在本机的退出测量，不代表所有资料库的固定耗时。
- 应用相关静态分析无 error/warning，保留生成协议文件的 3 项命名提示。全仓库分析还包含独立 demo 未解析依赖的既有错误，不将其宣称为全仓库零问题。

正式 UI 完整自动保存、完整 IO SDK 冻结及其他平台资格仍是开放项。第一方代码、SDK、文档和素材采用 AGPL-3.0-only；第三方依赖保留各自许可。
