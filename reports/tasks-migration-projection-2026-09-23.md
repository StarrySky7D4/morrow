# TaskId 迁移：宿主证据投影与独立验证

本轮新增 `workbench_host/src/tasks_migration.rs`，将 TaskId 迁移规划、实际插件捕获和上一轮核心原子迁移命令连接起来。工作台 UI 尚未开放迁移，不能将这一层接通记作 T31–T34 的完整产品验收。

## 固定的提交事实

- 使用独立 `morrow.workbench.tasks-migration.v1` 证据类型，原 V1/V2 内容投影不修改语义。六项宿主事实为投影版本、确定的操作 ID、完整源 Card 原件、选定插件包摘要、迁移器版本和目标格式。
- 规划先核对 V1 卡片与精确源基线，并检查请求、目标正文、完整目标 Card 的容量。固定迁移器 1 的任务操作与 ID 不依赖当前时间或每次重试的新随机数。
- 捕获入口只包装实际单任务记录，原始 invocation、completion、预算、退出状态、host call 数及 fuel 观察不改写。包、任务、请求及迁移输出均必须与计划对应。
- 新格式的阶段与三类计数来自插件契约；投影确认完整输出对应固定迁移规则，最终提交只调用核心独立迁移命令。标题、预览、附件、关联和未知字段保留原卡片事实。
- 提交不创建权限。提交连接必须对应原包摘要，且通过核心事务中两次有效授权核验；新包、撤销连接或过期权限不能因持有旧证据而重新得到写入权限。
- 事实解码拒绝重复字段、未知语义、非规范编码、超长原件及版本混用；证据仍保存原始归档，不把重新编码结果当作原证据散列。

## 独立核验范围

`morrow-content-replay` 增加新证据类型分派：先核对外部摘要及投影与原提交的对应性，再重放归档 Wasm。与旧验证器相同，结果不代表原始内容来源有权、当前授权有效或外部签名已验证。

投影一致性与真实执行重放是两个检查。即使伪造一组内部一致的执行观察，独立重放仍需比较实际执行结果及资源观察；不能凭投影通过输出 MATCH。

## 旧写入者与新版编辑

已复现并修正：旧 SetContent 即使持有有效授权及迁移后的最新修订，也可能用 V1 正文覆盖 V2。现在 Store 仅允许此旧接口新写入 format 1，门禁位于事务内、历史 operation 重试判断之后。已执行的历史操作仍返回原回执，不覆盖现在的内容；旧纯投影和历史 schema 1 含义保留。

新增可信宿主接口 VersionedContentChange 和 Command schema 2 的 SetVersionedContent（字段 8）。完整源 Card 作为事务内精确比较基线，正文修改保留源类型、格式和未知字段；回执解析从完整原件重建结果并核对摘要。新路径仍两次核验有效授权，失败不留下内容、操作或事件。具体格式的正文及插件证据须由宿主适配层验证；这不是新的通用 guest ABI，也不代表旧插件已经能编辑新格式。

V1 解码器保持冻结形状，历史未知字段 7/8 不获得新语义。schema 2 额外拒绝混用、重复的 oneof 动作。

## 已执行验证

- 核心关联回归：65 通过，0 失败，1 个原有子进程 harness 按设计忽略。覆盖旧直接接口/运行期命令以当前修订写 V2 的拒绝、原操作重试、版本感知编辑、完整源 CAS、最终授权拒绝及新旧命令边界。
- 宿主组合：34 通过，0 失败。包括迁移集成 4、固定历史样本 1、实际 TaskId guest 1，以及旧内容投影、捕获投影、偏好提案与独立 CLI 的兼容回归；不与之前报告重复累计。
- 迁移集成使用实际 Rust Wasm、受保护审计库及当前授权，验证同库重开、历史回执、管理器禁用/撤销/到期、原件变化、包替换、容量拒绝及无部分提交。
- 独立 CLI 在源库与保护材料移除后可重放归档；错误外部摘要拒绝。篡改 fuel 观察后即使纯投影内部一致，实际重放仍返回 mismatch。
- 固定 128 字节历史样本包含 2^53+1 修订、同名歧义、未完成项、独立阶段和内外未知字段；请求、输出、正文、核心命令散列及 TaskId 均为字面量断言。该测试使用合成观察，只检验确定性投影；未来版本仍必须保留原 codec 和 migrator 路径。
