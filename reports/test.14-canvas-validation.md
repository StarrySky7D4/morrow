# test.14 低强度磨砂与顶部背景修正

发布说明：以下保留发布前本地构建的验证记录与历史校验值。主线预发布已按新源码重建，最终附件校验值以 [test.14 发布记录](0.1.9-test.14-release.md) 为准。

日期：2026-09-12。应用版本 `0.1.9-test.14+23`；本轮未推送或发布 Release。

## 修正

- Windows 系统背景采样本身带有基础模糊。现在在滑杆前 20% 范围内使用连续平滑曲线混入磨砂层，让 0% 到 1% 只产生轻微变化；模糊半径与混合强度同时使用 280 ms 过渡，遵循系统动画开关。
- 归零时将背景层淡出到完全透明，保留合成对象以便反向平滑切换，关闭窗口时显式释放。
- 原生背景模糊与 Flutter 染色层移除顶部 32 像素排除区域，统一覆盖标题栏背景。前景内容仍保留标题栏安全间距，标题、按钮和组件不作为模糊输入。
- 工作台 Rust 宿主与插件仍为 test.13；独立 audit/test.14 原型尚未接入应用保存链路。本次应用版本升级仅反映以上外观修正。

## 验证

- Flutter 静态检查无问题。全套测试 73 项通过；真实 Rust 宿主集成项在通用测试中跳过，随后由打包脚本提供真实宿主与插件单独运行通过，共 74 项。
- Windows Release 构建成功。最终包内程序的自有红蓝条纹场景真实像素检查通过。前两次开发验证因遮挡拒绝采样；验证模式调整为短暂置顶且不激活的自有场景后通过，普通运行不改变窗口置顶状态。
- 31 个背景像素相对透明基线的 RGB 绝对差合计：1% 为 62，2% 为 201，10% 为 3564，30% 为 7130。这个数值是本机固定色块测试指标，不是通用感知强度单位。
- 标题栏行与画布行同步产生模糊、染色变化；不透明前景白色保持原值。恢复模糊和染色为 0 后，63 个采样点均恢复基线，没有黑底。
- 最终包工作台运行、原生模糊接口、WAV 播放与跳转、音频互斥、恢复不自动播放、Flutter 渲染检查通过。
- 包内 236 个文件逐项核对 SHA-256 通过。
