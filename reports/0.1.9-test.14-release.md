# Morrow 0.1.9-test.14 · Windows 测试预览版

**这是重构阶段的测试预览版（Pre-release），仅提供 Windows x64 预构建，不是稳定版。**

`test.1` 是 `0.1.x` 最后一个兼容原有数据类型的测试版。从 `test.2` 开始逐步重写，后续测试版本可能包含破坏性数据变更；架构与数据模型锚定后再发布 `0.2.0`。本版使用独立的 Rust 工作台数据目录，不自动导入或覆盖 test.1 旧资料。请保留旧版与原始资料备份，使用副本体验新版本。

## 本次更新

- Windows 默认进入 Rust 插件工作台：内容、配置与附件通过统一核心保存，Flutter 负责界面、输入和平台媒体承载。
- 每个组件和每张内容卡片提供独立材质设置页，默认继承主题，可单独调整磨砂、不透明度与颜色。
- 透明画布分别调整磨砂、染色不透明度和颜色；修复不透明度归零后的黑底，保持前景文字和控件清晰。
- 平滑磨砂 0%→1% 的变化，加入 280ms 过渡；磨砂与染色统一覆盖顶部标题栏背景。
- 完善偏好分段保存、内容创建／编辑／读取，以及 C／C++／Rust 插件 SDK。插件系统仍在建设中。

## 下载与运行

下载 `morrow-0.1.9-test.14-rust-workbench-windows.zip`，**完整解压**后运行 `morrow_studio.exe`。请保留同目录 DLL、宿主程序、`plugins` 和 `data` 文件夹，不要只复制 EXE。

本次仅上传 Windows x64 ZIP 和对应 SHA-256 校验文件，不提供 Web 或 Android 构建。

## 当前限制

- 工作台尚未接入自动审计封存，待处理事件默认最多 1024 条或 64 MiB；持续大量编辑可能触及容量限制。
- 通用正文单次写入暂为 32 KiB，整份偏好上限 4 MiB；大正文写入、旧数据导入、完整插件管理及全平台验收仍在推进。
- 源码包含内部 test.18 核心／审计原型；应用版本仍为 `0.1.9-test.14+23`。独立审计初始化、保护密钥和封存工具不代表默认工作台已自动接入这些能力。
