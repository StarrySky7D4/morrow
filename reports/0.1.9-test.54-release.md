# Morrow 0.1.9-test.54 · Windows 测试预览版

**重构阶段的测试预览版（Pre-release），仅提供 Windows x64 预构建，不是稳定版。** 应用版本为 `0.1.9-test.54+58`。

本版针对已有内容库启动时的重复读取与校验，缩短加载界面到工作台显示的等待。

## 本次优化

- 当前格式、已绑定身份的原生 WAL 活动库，将受管打开路径中的四次完整校验合并为持锁事务内的一次；每次重新打开仍执行完整校验，旧格式迁移及其他后端保留原检查路径。
- 证据按两份有界数据并行解码与校验，数据库读取仍由原线程执行；小库、单核和 Web 使用串行路径，线程创建失败时回退。
- 同一次校验事务内复用已完整验证的证据大小和归档摘要，减少重复解码与分块扫描。每类最多缓存 4,096 条轻量元数据；超限项回退完整检查，引用顺序、重复引用计费、摘要与关联约束继续核对。
- 复用热点 SQL 预编译语句，移除归档加载后的重复捕获绑定检查。缓存不保存正文、不写入数据库、不跨启动保留。
- 补齐中文、英文、俄文、法文、德文、西班牙文、日文、韩文、葡萄牙文 README。根目录默认中文，各语言统一当前状态、下载与构建入口；旧 README 保存到历史文档，避免把早期阶段限制误读为当前状态。

本版没有新增数据迁移，也没有更换内置插件包或修改 SDK 契约。

## 性能证据

使用同机约 100 MB 实际内容库的隔离副本，注册活动库后启动进程；不打开原始用户库。最后一轮读取优化与上轮并行版按 AB、BA、AB、BA 交替，各测四次：

| 中位数指标 | 上轮并行版 | 本轮最终优化 |
| --- | ---: | ---: |
| 宿主就绪（Dart 入口起） | 1.810 s | 0.888 s |
| 工作台首帧（Dart 入口起） | 2.111 s | 1.189 s |
| 加载遮盖完全移除（Dart 入口起） | 2.222 s | 1.299 s |
| 加载页出现到遮盖移除 | 2.093 s | 1.181 s |

最后一轮使遮盖移除时间再缩短约 42%。此前第一轮合并重复检查的独立三次测量，遮盖移除中位数由 7.677 s 降至 2.393 s；两组属于不同阶段，未将它们合并为一次配对实验。

以上是进程重启测量，副本注册可能预热系统缓存，不是清空文件缓存或重启电脑后的冷启动保证，也不是所有设备的性能承诺。仍有个别约 39–42 ms 绘制峰值。完整记录见 [开库流程](library-open-optimization-2026-09-21.md)、[并行校验](library-open-parallel-2026-09-21.md)及[读取与关联校验](library-read-verification-2026-09-21.md)。

## 下载、许可与兼容性

完整解压 `morrow-0.1.9-test.54-rust-workbench-windows.zip`，运行 `morrow_studio.exe`；保留同目录 DLL、宿主、`plugins`、`data` 和许可文件。附件同时提供对应源码 ZIP 和 SHA-256 清单，包内 `SOURCE.txt` 指向对应提交与标签。本次不提供 Android 或 Web 构建。

`test.1` 是 `0.1.x` 最后一个兼容原有数据类型的测试版。此后的 test 版本逐步推进重写，可能包含破坏性数据变更；架构与数据模型锚定后再发布 `0.2.0`。本版继续使用独立 Rust 工作台，不自动导入 test.1 旧资料。体验前请备份内容库与原保护文件；保护文件与 Windows 用户绑定，仅复制数据库不能完成跨账户迁移。

第一方代码、SDK、文档和素材采用 **AGPL-3.0-only**；test.1 及更早版本、第三方依赖保留原许可。

## 验证与边界

- 本次优化的最终 Core 全套 568 项、Audit（含故障注入）97 项及真实 Windows 宿主／Rust guest 集成 2 项通过；Core 另有 1 项既有忽略。
- Audit 全目标严格 Clippy 通过；Core 全目标仅豁免既有测试 `cloned_ref_to_slice_refs` lint 后通过，不宣称无豁免通过。
- 发布版本的 Windows Release 已重新构建，EXE FileVersion 与 ProductVersion 均为 `0.1.9-test.54+58`，两项真实宿主集成复测通过。完整打包目录另以隔离库副本启动一次，宿主就绪 0.913 s、工作台首帧 1.217 s、遮盖移除 1.330 s（均从 Dart 入口起），进程正常退出；该单次检查不替代上面的四组对照实验。
- 打包宿主与已完成全套测试的最终宿主摘要一致，内置插件摘要保持不变。九种 README 的相对链接、版本、章节和构建命令一致性检查通过，译文尚未经母语使用者全面审校。本轮没有重复执行全套 Flutter 测试，也没有 Android、Web 或其他平台运行验收。
- 该实现仍需随历史增长执行全量校验；目前是有界分批并行，尚未实现读取与计算重叠的完整流水线或自动历史清理。
- 插件系统与完整 IO SDK 尚未冻结。跨重启 Unknown 核对、完整文件系统、三语言 IO SDK 和跨平台资格继续按开发看板推进。
- 性能报告保留其测量时的版本号与产物摘要；本版发布包的最终摘要以 Release 附件清单为准。
