# 风格过渡与输入凹槽连续性

日期：2026-09-24。承接[五种实验风格接入](experimental-styles-2026-09-24.md)，应用和插件仍分别为 `0.1.9-test.54+58`、`0.1.9-test.54.5`。仅更新本地源码与 Windows 预览，没有提交、推送或发布。

## 问题与修正

共用表面原本只对 depth 做动画。两个风格的 depth 都为 1 时，风格画法和圆角立即替换；切回扁平也立即选择无绘制的 painter，旧边缘突然消失。

现在 `NeumorphicSurface` 保留一个子节点和一个控制器，插值固定七项风格权重、depth、圆角、表面色和焦点色。快速 A→B→C 从当前可见状态继续，不回到 B 的完整画面。回到扁平时边缘淡出。按压仍走凸起/下沉状态，不复制内容、路由或编辑器。稳定状态直接使用原绘制器；过渡只混合边缘绘制，不对整棵内容树叠加 opacity 或 saveLayer。

减少动画、隐藏 TickerMode 和零深度→零深度场景直接收敛。无边缘的 Glass 外包层不因风格参数变化而额外启动动画；玻璃本身保留已有材质过渡。

五种实验风格的输入框使用同一种 OutlineInputBorder 派生类型，避免 Flutter 在不同派生边框之间插值时退成普通轮廓、突然丢失内凹。凹槽保存固定的黏土/器物权重与明暗系数，最多四次边缘绘制，不保存历史 Border 或 Widget。显式启用态、圆角、焦点/错误边线继续保留；默认中心不填色。

独立复核发现：风格和主题同时切换时，旧凹槽可能过早采用目标深浅色。新增确切端点返回和明暗混合；像素回归覆盖浅色/深色的十种组合间 90 条有向路径。

## 验证与边界

- 最终 **45 项 UI 组合通过**，日志 `build/style-transitions-final-ui.log`。其中新增四项覆盖中断续接、焦点/草稿/State 保留、扁平淡出、减少动画/隐藏/零深度，以及输入边框端点与透明中心。
- 输入像素测试实际绘制 Border，比较每条路径的起止附近帧和中间帧；绘制透明度为零不留下内容或背景。这是绘制正确性检查，不是帧性能结论。

- Windows Release 预览重建，日志 `build/style-transitions-windows.log`，入口仍为 `build/windows-corners/x64/runner/Release/morrow_studio.exe`。
