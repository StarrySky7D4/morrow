# 文件变更恢复界面验收（2026-09-27）

本轮在 IO 设置加入 Windows 原生文件变更恢复面板，连接上一轮的有界发现、断点续扫、只读核对与真实退出／确认流程。开发分支 `codex/io-safety-refactor`，基线 `b9225f64f6c62584ad7243e30249d8a088bcb155`；未提交、推送、打包或发布，SDK 仍未冻结。

## 行为

- 从当前确认的插件目录选择已启用、可用、声明并批准 Create／Replace／Delete 范围的包，输入精确原操作主体标识和任务期限，显式启动原计划发现。主体不从包名猜测，也不裁剪前后空格；无效标识在发送前拒绝。
- 每页最多八个候选，显式领取与翻页，不解析或展示原件二进制正文。计划行按页面序号呈现，完成独立核对后才显示宿主确认的操作身份与结果；元数据摘要展示尚可继续改善。
- 选择计划后先结束／停止扫描，观察实际退出，必要时修复清理，最后确认归还，再以当前目录修订显式核对。停止不等于退出；页面不通过业务调用自动读页、续租或重新执行文件效果。
- 续扫使用已交付页的原始范围与 checkpoint，忽略之后修改的表单主体，使用新的 submission 并重新校验当前包审批。过期 checkpoint 由宿主明确拒绝。丢页后不能悄悄跳到下一页；允许清理后从上次保存位置继续或重新扫描。
- 新 `MutationRecoveryViewState` 每个 session 稳定复用，只保留一页、一个绑定原范围的所选计划和一个最近核对结果；离页或 ack 后仍可展示。新页不重新绑定之前选中的计划，更换后端不继承旧会话。缓存不授权，也不改变持久库。
- UI 可见且属于本会话的任务存活时，每秒只读刷新状态；隐藏、销毁、后端切换或退出后停止页面轮询。业务会话不随 Widget 销毁；无任务时不持续轮询。其他活动任务提示返回原面板。
- 最近发现页、所选计划范围及最近核对结果分别标注。Observed 与 OS 成功分开显示；Unknown、Prepared 或缺少效果原件不会显示成功。
- 沿用设置页主题色、圆角与组件材质容器，新增组件自定义设置名称。九种语言增加 30 个外置文案，重新生成官方 Flutter getters 和 PB/LZ4 资源。

新增 widget 用例覆盖精确主体、无效主体、显式领取／翻页、丢页门控、保留原范围的续扫、所选计划清理后核对、Unknown 不显示成功、离页返回、后端隔离、已选计划撤权后禁止续扫／核对及隐藏停止轮询。窄屏复核移除了早期放大视口的测试绕行：确认是 TextField 失焦后的延迟 showOnScreen 与测试定位竞争；先等待焦点滚动稳定再定位按钮，默认 800×600 和 320×640 都通过完整续扫，无需产品布局绕行。

真实宿主测试扩展了正常关闭并重新开库后的展示模型验证：从真实发现页选择原计划，任务 ack 后选择仍在，分别核对真实 Observed／Prepared，再次 ack 后结果保留。它不是完整应用窗口的手动验收，也不是强制崩溃整链验收。
