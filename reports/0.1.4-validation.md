# daemon 0.1.4+5 — 2026-09-09

- Fixed window region coordinates to match the Flutter client canvas, including invisible frame offsets. The app owns all four corners and reapplies the region after window position, frame, size and DPI changes.
- Lyrics use same-name UTF-8 LRC files before embedded audio tags, then optional LRCLIB lookup. Manual search/version selection and plain-text viewing remain available. Network results cannot overwrite a newer manual import or another track.
- Added distinct inbox, project, experiment and favorites views with their own filters and actions. Existing content is migrated with default stages.
- Added mixed text/file paste, multiple attachments, media previews and external opening/export for CAD/Blender and other files. Imports preserve separate file copies; canceling an edit cleans newly imported unused files.

Validation:

- Flutter analyze: no issues.
- Flutter test: 30 passed. Coverage includes ID3/FLAC/MP4 lyrics, sidecar priority, ambiguous online results, late-response races, offline behavior, attachment persistence, selection-aware mixed paste, experiment-field paste, project promotion/progress and all four pages at 390px width.
- Windows integration test: 2 passed. Native region queries confirm all four corners at radius 0/20/32, resize and maximize/restore. Actual native storage imports preserve Chinese filenames and every byte for five attachment types, restore from saved references, and clean their test copies without changing originals. File payloads in this storage test are synthetic, not playable media or valid CAD models.
- LRCLIB API smoke check returned lyric-bearing search records; no retrieved lyrics or QA media are bundled.

- Windows Release and Web release builds succeeded. Web retains the existing optional CupertinoIcons font warning.
- Sharing ZIP: `dist/daemon-0.1.4-windows-x64.zip`, 35,520,008 bytes; all 51 files match staging by SHA-256.
- ZIP SHA-256: `c4c96ee4c6e61dde8c4ae08d902ece0e83e8625b5f57f1b5cf35f702394eb468`.

Limits:

- Web sidecar lyrics must be selected alongside audio or imported manually. Browser embedded-tag parsing covers MP3 ID3v2.3/2.4 USLT, FLAC comments and M4A/MP4 lyrics. Other tags/formats use external lyrics or search.
- Clipboard content is limited to formats exposed by the source app and browser. CAD/Blender attachments are original files opened by an associated application, not an embedded modeling editor. Clipboard dispatch is covered with injected mixed content; this run did not exercise every source application's native clipboard formats or external application associations.
- Cross-monitor DPI transitions and long-running native accessibility stability were not exercised. This change does not establish resolution of the previously recorded Flutter accessibility engine issue.
