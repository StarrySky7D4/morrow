# test.16 核心原子封存确认

日期：2026-09-12。核心与审计模块为 `0.1.9-test.16`；Windows 应用包仍为 test.14，未重新发布应用，未推送或发布 Release。

## 实现与范围

签名契约与验签代码统一迁入 `core/schemas/audit.proto`、`core/src/audit.rs`，独立审计归档与验证工具复用同一实现。核心不接受外部回执作为删队列凭证，而是独立核对固定日志身份／公钥、签名链和本库的每条原始提交字节。

`Store::seal_pending` 在同一事务内保存原始签名段、关联永久事件顺序、确认待封存队列；同一签名段重试返回已封存。operations、内容和历史附件引用不删除。核心保留本地签名原件，因此外部归档副本不可用不等于本地证据丢失。

格式 4 在同一事务中核验、建立永久事件索引并升级到格式 5；损坏旧库迁移失败会保留版本和原始记录。格式 3 与更旧库仍拒绝，未自动导入 test.1 用户资料。旧核心不得用于写入新格式库。

打开已封存数据库必须由宿主传入可信日志身份；不能读取段内公钥后自行信任。新只读入口不创建或升级数据库，独立工具通过 `--core-store DB` 核验核心的签名原件、事件对应及内容完整性。
