# Morrow 0.1.9-test.55 · Windows 测试预览版

**本版为重构阶段测试预览（Pre-release），仅提供 Windows x64 预构建，不是稳定版。** 应用版本 `0.1.9-test.55+59`，内置工作台插件 `0.1.9-test.54.6`。

## 本版变化

- 新增实验风格：纸感、黏土、Fluent、粗野主义、工业面板，与默认扁平和 Neumorphism 共七种。风格列表默认收起；支持深度的风格提供 0–200% 调节，组件可单独覆盖或跟随主题/其他组件（禁止循环跟随）。
- 打磨按钮、输入框、滑块、开关、复选框的浮雕/凹陷和过渡，处理切换中断、减少动画及明暗模式；修正开关图标切换和拖动时投影不对齐。
- 限制组件外投影范围，减轻高深度阴影，增加紧密按钮间隔；悬停不再随卡片宽度向外膨胀，减少不同风格下相邻组件粘连。
- 修复停用内置工作台插件后无法保存应用设置，以及字体设置页脱离共享背景而异常透明的问题；卡片操作仍受插件权限限制。
- 内容服务退出使用专用界面，可“转入后台继续关闭”；再次按窗口关闭键亦可转入后台。失败或后台等待 30 秒仍未结束会重新提示，真实服务退出后自动关闭；不强杀服务、不提前放开资料库所有权。监听器与工作线程并行收尾。
- 推进编辑恢复底座：持久交接提案、恢复入口、历史提交证明、附件归属及捕获完整性校验。**正式编辑器 UI 的完整自动保存尚未接通**，不会把这些底座能力宣传为已完成 autosave。
- 与上次 test.54 Release 相比，包含此前已推送但未发布的字体自定义、外置语言包、组件跟随和跨版本迁移工具。迁移支持旧 JSON 与重构内容库，使用预检和新目标目录，保留原数据。

## 下载与兼容性

完整解压 `morrow-0.1.9-test.55-rust-workbench-windows.zip`，运行其中的 `morrow_studio.exe`；保留 DLL、宿主、`data`、`plugins` 与许可文件。附件同时提供对应源码 ZIP 和 SHA-256 清单，包内 `SOURCE.txt` 指向源码提交与标签。本次不提供 Android/Web 构建。

`test.1` 是 `0.1.x` 最后一个兼容原有数据类型的测试版。后续 test 版本逐步推进大规模重写，可能包含破坏性数据变更；架构与数据模型锚定后再发布 `0.2.0`。升级前备份内容库与原保护文件；保护文件与 Windows 用户绑定，仅复制数据库不能完成跨账户迁移。迁移工具不会自动覆盖原库。

第一方代码、SDK、文档和素材采用 **AGPL-3.0-only**；test.1 及更早版本、第三方依赖保留原许可。

## 验证与已知边界

- 本次发布回归：168 项 Flutter/Dart 测试通过；4 个分阶段用例在独立客户端进程中补跑，seed/recover 各 4 项通过。涵盖风格/字体/保存、草稿与附件、恢复及真实宿主关闭。
- 协议生成检查、九语言生成一致性检查通过。退出变更的 Rust 服务 28 项及 CLI EOF 3 项在本轮修复中通过；详细证据见仓库 `reports/surface-shutdown-fixes-2026-09-24.md`。
- 以 `lib/main_rust.dart` 重新构建 Windows Release；EXE FileVersion/ProductVersion 均为 `0.1.9-test.55+59`。完整打包目录在隔离库自检中成功渲染、验证原生模糊 API 和音频播放/定位，并以退出码 0 结束。
- 后台关闭不代表服务立即结束，已接受的在途请求仍需安全收尾；没有宣称退出耗时或 GPU 帧率的新测量结果。test.54 的开库性能数字仅作为历史报告保留。
- 正式 UI autosave、完整 IO SDK 冻结与其他平台资格仍开放。九种译文尚未经过全面母语审校。
