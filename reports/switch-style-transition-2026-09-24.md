# 开关轨道与凹槽的风格交接

日期：2026-09-24；开发工作树 `codex/io-safety-refactor`，基线 `e89f4ff`。应用 `0.1.9-test.54+58`、内置插件 `.54.5` 不变。本轮仅更新本地代码和 Windows 预览。

## 复现与实现

原 NeumorphicSwitch 根据当前风格布尔量立即将原生轨道设为透明，同时立即增加或撤掉凹槽 painter。已有开关节点没有重建，但装饰发生跳变。新增测试先在新拟态离开时检测到 trackColor 立即为 null 而失败，见 `build/switch-style-baseline.log`。更早一次测试把无状态 Switch 当作 State 读取导致的测试错误已修正，不作为缺陷证据。

改为 180 ms 的可中断装饰动画，固定原生 Switch 层次，仅交接原生轨道透明度与凹槽强度，独立插值明暗光照、表面与强调色和凹槽禁用强度。反向从当前显示状态继续；开关数值动画仍保留原有行为。高对比与 Apple 自适应立即回到原生轨道，减少动画或隐藏 Ticker 时收敛并停止装饰控制器。

交接期间优先采用有效 SwitchTheme 的状态颜色，缺省时依据本机 Flutter 的 Material 2/3 默认颜色补全，以便渐变至透明；权重归零后不再覆盖原生属性。保留 activeThumbColor 的原生回退优先级。没有增加旧开关副本、saveLayer 或新的业务回调。

## 验证

- 最终 **62 项相关回归通过，无跳过**，日志 `build/switch-style-tests.log`。五项新增测试覆盖交接/反向、颜色终点、特殊模式、交互语义与明暗像素，其余覆盖现有风格、滑块、输入、保存、透明、主题和随身听。
- 32 组 Material 2/3 × 浅深色 × 启用/禁用 × 开/关 × 默认/自定义轨道颜色，在退出前 179 ms 和归零原生终态的归一化像素差异小于 1%。测试同时提供 activeThumbColor，检查调用方属性优先级。归一化像素差异并非性能指标。
- 新拟态明暗过渡在 89/91 ms 的邻近像素差异小于 4%；反向初帧与原显示结果差异小于 0.1%，最终回到浅色原始结果。
- 原生开关在两种文字方向中，按住拖动并依次切换七种风格，保持同一 Element 和键盘焦点；拖动、空格键切换、禁用后不再回调、启用/选中/焦点语义均通过。测试初次拖动距离未超过原生识别阈值，调整为先跨阈值再移动后通过；没有为适应测试更改产品手势。
- 高对比、减少动画、隐藏模式及 iOS/macOS 的自适应配置通过 Widget 测试；这不代替 Apple 设备或平台构建验收。
- 原浅深新拟态控件金图普通比较通过，本轮没有更新金图。
- `lib/neumorphic_controls.dart` 与新增测试静态分析无问题，日志 `build/switch-style-analyze.log`；定向差异检查通过。
- Windows Release INSTALL 退出 0，正式入口 `lib/main_rust.dart`，日志 `build/switch-style-windows.log`；产物 `build/windows-corners/x64/runner/Release/morrow_studio.exe`，运行须保留同目录依赖。源码/日志/产物 SHA-256 见配套 JSON。
