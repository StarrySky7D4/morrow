# Morrow · 明隙

留一点空间给明天的想法。项目原名 daemon，现统一命名为 Morrow；代码包名为 `morrow_studio`。改名兼容策略见 [重命名说明](docs/RENAMING.md)。历史发布附件保留原名，新构建使用 `morrow-*`。

[下载稳定版本](https://github.com/StarrySky7D4/morrow/releases/latest) · [下载 0.1.9-test.1 测试版](https://github.com/StarrySky7D4/morrow/releases/tag/v0.1.9-test.1) · [Apache-2.0](LICENSE)

用 Flutter 构建的灵感工作台。支持 Windows 与 Web，界面由 Flutter 绘制，使用 shared_preferences 保存本地内容、flutter_acrylic 实现 Windows 原生透明窗口。

Android 工程与移动端文件适配已加入，提供 ARM64 调试签名测试包；构建方法与当前验证范围见 [Android 构建说明](docs/ANDROID.md)。

- 玻璃材质：磨砂（22px 背景模糊）、超透（1px 轻微模糊、常规组件 2.5%–12% 遮罩、细亮边缘；编辑弹窗保留阅读衬底）与液体玻璃，三种材质支持 360ms 连续过渡。磨砂提供 20%–100% 不透明度滑条，实时预览、松手保存。
- 主题：白色、自定义、深色，与三种玻璃材质独立搭配。设置中的「主题色彩色罗盘」统一调整按钮、开关、滑条、选中态、卡片图标和面板色调，支持拖动选色、明暗与 HEX 输入、实时预览、取消还原、应用保存和恢复默认；深浅主题自动调整控件颜色明暗，画布自定义色单独保留。
- 背景：默认光晕、纯色、纹理、透明，独立于主题与材质，共 36 种组合。纯色提供四个预设和 HSV 调色罗盘，可拖动色相／饱和度、调整亮度，或输入 HEX 精确配色。
- 纹理：内置纸感点阵，支持导入本地图片、GIF、视频，或填写 HTTP / HTTPS 媒体直链。图片／GIF 最大 25 MB，视频最大 150 MB；按画布比例铺满裁切，视频静音循环，动态素材可暂停／继续或恢复内置纹理。
- 页面切换：300ms 淡入淡出与轻微位移，背景切换 360ms 渐变；系统启用减少动画时，页面和背景立即切换。
- 组件切换：收藏、清单、导航、筛选卡片与设置面板增加淡入、缩放和尺寸过渡；减少动画时停止动态背景。
- 弹窗：统一圆角玻璃面板、标题图标与底部操作区，淡入缩放开合，跟随主题、玻璃材质与磨砂不透明度；纯色背景继承自定义色，纹理背景使用透明弹窗底层，让外部素材透过玻璃。
- 各页有独立用途：总览聚合内容；灵感收件箱支持待整理／已整理和转为项目；小项目有阶段与可勾选的进度清单；实验室记录假设、过程和结论；收藏库按图像／音视频／文件／文字筛选。
- 新建与编辑支持 Ctrl+V／粘贴按钮，按光标位置插入文本，同时接收截图、复制的图片、音视频、CAD、Blender 等文件；也可多选导入。每条最多 20 个附件，单个最大 200 MB，纯文件也能建立记录。图片／GIF 可缩放预览，音视频可手动播放；CAD／Blender 保留原文件，可另存或用本机默认软件打开，不提供内置建模编辑器。
- 保留搜索、收藏、清单勾选、快速记录，以及最近添加／收藏优先／标题排序。搜索包含附件名与实验记录。
- 删除后 8 秒内可撤销；编辑时保留收藏和仍存在的清单完成状态。
- 自动保存：灵感、收藏、清单、日常小事，以及主题／材质／背景／自定义色／不透明度／素材选择和播放开关，在刷新或重启后恢复。保存失败会提示重试；无法读取的原数据不会被自动覆盖。
- 自适应布局：宽屏三栏，平板两栏，手机单栏与菜单导航。小于 1050 像素时设置默认关闭，点击设置进入独立页面，通过返回按钮或系统返回回到原内容与滚动位置；窄屏设置的打开状态不影响宽屏侧栏偏好。进入和返回采用 320ms 顺序淡出／淡入与轻微滑移，两页不重叠；减少动画时立即切换。
- 快捷键：`Ctrl+K` 搜索，`Ctrl+N` 新建灵感。
- Windows 标题栏与边框跟随主题、纯色色值和透明背景；保留拖动、双击最大化、边缘缩放及窗口按钮。搜索框与设置按钮固定右对齐。

- 形状与色调：圆角幅度 0–32，拖至 0 即为方角；Windows 窗体边框有独立圆角滑条，最大化自动展平。白色、深色是固定方案，只有自定义下可展开调整灰度与明暗；折叠状态默认关闭，切换预设保留自定义参数。旧浅灰主题自动迁移为自定义。
- 随身听位于设置「此刻的小事」下：本地音频导入、小封面、上一首／暂停／下一首、拖动进度、默认折叠的播放列表；支持自选封面，按同名歌词文件 → 音频内置歌词 → 联网搜索的顺序读取歌词，保存列表与歌词，重启不自动播放。单首音频最大 150 MB，浏览器的编码支持决定 Web 可播放格式。
- 背景默认静音，可开启声音；播放背景声音时暂停音乐并隐藏播放器，关闭背景声音后可手动恢复音乐。切换素材时释放旧媒体，避免声音重叠。
- 左下角与底部新增多条提示语，每 14 秒渐变轮换，减少动画时停止轮换；底部固定在可视区域，不随页面滚动或切页消失；播放音乐时可切换为同步歌词，无歌词显示歌曲名。

## 液体玻璃与富内容捕捉

侧边栏与设置栏支持收起／展开动画并保存状态。玻璃质感新增液体玻璃，默认、纯色、纹理和透明四种画布均可独立启用液体效果。新建灵感支持 Markdown 编辑与实时预览，扩展 Word／Excel 富文本、表格、PowerPoint 对象预览和原始 Office 附件导入。详见 [使用方法、格式支持和验证范围](docs/RICH_CAPTURE.md)。

## 运行

需要 Flutter 3.44 / Dart 3.12 或兼容版本。

```powershell
flutter pub get
flutter run -d windows
# 或在浏览器预览
flutter run -d chrome
```

```powershell
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

构建后可用 `node tool/preview.cjs` 启动本机预览，地址为 `http://127.0.0.1:8765`。
Windows 构建：`flutter build windows`，运行 `build/windows/x64/runner/Release/morrow_studio.exe`，分发时需保留整个 Release 目录。

个人分享打包：构建后运行 `pwsh -File tool/package_share.ps1`，生成 `dist/morrow-<当前版本>-windows-x64.zip`。它包含全部运行依赖，接收者完整解压后双击应用即可。同时构建 Web 后，加上 `-IncludeWeb` 可生成 Web ZIP 和 SHA-256 校验文件。脚本的 `-CrtDirectory` 参数可以指定本机 Visual Studio 的 x64 CRT redist 目录。

## 歌词与附件

导入 Windows 音频时，先找原文件目录下同名的 UTF-8 `.lrc`（后缀大小写不限），再读取音频标签。Web 无法任意读取音频所在目录，请同时选择同名音频和 `.lrc`，或在播放列表中手动导入 `.lrc`／`.txt`（最大 1 MB）。Web 内置标签支持 MP3 ID3v2.3／2.4 的 USLT、FLAC 注释和 M4A／MP4 歌词标签；其他编码或标签可使用外部歌词文件。

没有本地歌词时，默认向 LRCLIB 搜索；只发送歌名与歌手，不上传音频。自动填充要求匹配歌名、歌手及已知时长；不能确认的版本留给「搜索歌词」手动选择。可关闭自动联网；离线仍能使用本地歌词。带时间轴的歌词随播放切换，没有时间轴的歌词保留原文并提供全文查看。歌曲信息不完整时可在搜索弹窗修正关键词。

Windows 可粘贴资源管理器复制的文件和截图；Web 剪贴板取决于浏览器授权与剪贴板格式，读取失败时可用「导入文件」。CAD／Blender 的复制对象如果不是系统可读取的文件，请先在原软件保存文件后导入。附件保存独立副本，不修改源文件。

## 透明与保存范围

Windows 原生承载层始终保持透明；透明画布的液体效果保留边缘高光，中央不铺设遮罩，不切换原生模糊模式。Flutter 在圆角内绘制默认、纯色和纹理背景，避免视频圆角外残留原生实色方角。Windows 透明模式会透出窗口后面的桌面或其他窗口；Web 输出透明画布，透出宿主网页背景，独立浏览器页面通常显示浏览器的白色底，不会透出操作系统桌面。透明画布不会铺设假的棋盘格背景。玻璃面板自身保留渐变遮罩和描边；Flutter 背景模糊作用于应用内绘制内容，不会对后面的其他 Windows 窗口做局部物理折射或模糊。

Windows 数据由平台插件保存在当前用户的应用支持目录，导入素材另存到其中的 textures 目录，不修改原文件。Web 内容与外观参数保存在当前浏览器、当前站点来源的 localStorage，本地导入的媒体保存在 IndexedDB；两个平台不自动同步。清理浏览器站点数据会清除该浏览器保存的内容及素材。切回内置纹理不删除已导入的素材副本。

网络采集使用媒体文件直链，普通网页分享地址需要先找到原始媒体地址；远端服务必须允许访问，Web 图片还需允许跨域加载。视频编码支持取决于播放平台，Web 优先使用浏览器支持的 MP4 或 WebM。素材失效、浏览器容量不足或格式不可用时会提示错误；无法加载的背景回退到内置纹理。播放开关会保存，播放进度不保存。未连接后台守护进程或云端服务。

## 验证

v0.1.9-test.1 的构建、测试和分发校验见 [发布验证记录](reports/0.1.9-test.1-release.md)，历史记录见 [v0.1.8](reports/0.1.8-release.md)。下述实窗与媒体交互检查包含此前版本的验证，本次未重新进行实窗集成测试。

- `flutter analyze`：无问题。
- `flutter test`：桌面／手机的 36 种外观组合、搜索与收藏、新建与编辑、清单恢复、删除撤销、快速页面切换、减少动画设置、20% 不透明度下限、自定义色恢复、紧凑弹窗、媒体地址校验、图片铺满画布与背景切换。
- Web 发布构建与 Windows Release 构建已完成；Windows 原生透明背景已通过实际窗口检查。
- 当前共 71 项单元／组件测试通过（含四种画布独立液体效果、材质过渡、透明像素、富内容粘贴、更名数据迁移和 Android 布局测试），另有 Windows 实窗集成测试验证四角在圆角 0／20／32、缩放和最大化恢复后的区域；包含音频互斥、切歌竞态、播放列表、歌词同步、提示轮换、圆角和灰度恢复，以及宽屏／窄屏控件对齐和标题栏外观检查。Windows 实机验证了深色标题栏、桌面透明、最大化与还原。
- 此前 Windows 实机验证了图片、GIF、MP4 导入、播放／暂停和视频重启恢复；Web 验证了 GIF 本地导入与刷新恢复、MP4 直链播放／暂停、视频背景上的材质切换。已修复图片未铺满画布和 Web 视频拦截鼠标点击的问题。

新增插件后若增量构建使用了旧插件注册文件，可关闭运行中的应用后执行 `flutter clean`、`flutter pub get` 再构建；发布前应检查实际导入流程。
