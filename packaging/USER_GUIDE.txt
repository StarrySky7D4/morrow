Morrow — 杂事有序，奇想自由

系统要求：Windows 10 1809 或更高版本，x64。推荐 Windows 11。

完整解压 ZIP，进入 morrow 文件夹，双击 morrow_studio.exe。
请保留同目录所有 DLL 和 data 文件夹，不要只复制 EXE，也不要在压缩包内直接运行。
应用已附带 Flutter 引擎、视频解码库和 Visual C++ 运行库，无需安装开发工具。

使用
- 右侧「空间外观」切换磨砂／超透及白色／自定义／深色主题。
- 磨砂不透明度为 20%–100%；纯色可用调色罗盘或 HEX 输入。
- 背景支持默认、纯色、纹理、透明；纹理可导入图片／GIF／视频或媒体直链。
- 图片和 GIF 最大 25 MB，视频最大 150 MB。视频默认静音循环，可暂停；开启背景声音时暂停音乐并隐藏播放器。
- 圆角幅度拖至 0 即为方角；「窗体圆角」独立调整 Windows 边框，最大化时自动展平。白色／深色为固定方案；选择「自定义」后点击「调整自定义色调」展开灰度和明暗滑条，默认折叠。
- 「此刻的小事」下方是随身听：点击 + 导入本地音乐，支持上一首／播放暂停／下一首与进度拖动。播放列表默认收起。
- 点击小封面可更换图片，导入时优先读取同名 UTF-8 LRC，然后读取音频内置歌词，再联网搜索；展开播放列表可手动导入 LRC／TXT 或选择搜索结果；开启「底部显示歌词」后随歌曲进度切换。
- 支持 MP3、WAV、FLAC、M4A、AAC、OGG、OPUS，单首最大 150 MB。保存列表、封面与歌词，重启后不自动播放音乐，背景默认静音。
- 左下角与底部提示语定时淡入淡出；底部悬浮固定，不跟随页面滚动，可在提示语和歌词间切换。
- 歌词联网使用 LRCLIB，只发送歌名和歌手，不上传音频；可在播放列表关闭自动联网。没有时间轴的歌词可查看全文，不会伪造同步时间。
- 收件箱整理灵感并可转为项目；小项目跟踪阶段与清单进度；实验室记录假设和结论；收藏库按素材类型筛选。
- 新建／编辑可 Ctrl+V 粘贴文本、截图或资源管理器复制的文件，也可多选导入图片、音视频、CAD、Blender 等文件。每条最多 20 个附件，单个不超过 200 MB。
- 图片／GIF 可预览，音视频手动播放；CAD／Blender 等保存原文件，点击交给本机对应软件打开，也可另存。原软件内复制的建模对象需先保存为文件。
- Ctrl+N 新建灵感，Ctrl+K 搜索；支持收藏、分类、清单、删除后撤销。

数据与升级
- 数据和导入素材保存在当前用户应用支持目录，而非程序文件夹。
- 新版解压到新的文件夹即可运行，会继续使用当前用户的已有数据。
- 个人内容不会随这个 ZIP 自动携带到另一台电脑。
- 本应用没有账户、云端同步或后台服务。访问网络素材时向对应素材服务请求内容；自动或手动搜索歌词时连接 LRCLIB。

背景说明
- Windows 透明模式透出桌面；玻璃局部模糊针对应用内画布。
- Web 版透出宿主网页背景，不能透出操作系统桌面。
- 网络素材须为有效直链；Web 素材受浏览器编码及跨域策略限制。
- 素材加载失败会提示并回退内置纹理。
