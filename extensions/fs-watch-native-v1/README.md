# Original Windows directory observation resources

Experimental trusted low-level source. This crate is not connected to the
production package or owner routes and confers no plugin authority. An eventual
original host must reserve complete resource/output budgets, capture an async
directory plus protected ancestors, sample its original clock, and require
explicit watch approval. FileList approval cannot authorize a watch.

The owner consumes the exact original File once, verifies identity and actual
async mode, and never reopens, duplicates, or adopts a numeric handle. It owns a
fixed aligned buffer, OVERLAPPED and a unique event. One read/frame may be pending.
It retains original buffers/handles on ambiguous native outcomes and does not
retry Unknown. Retirement requests at most one cancellation, separately proves
completion, then closes each original handle once. A close capability is not
delivery, business success, shared-budget release or worker-join proof.

The explicit `qualification-probe` feature enables a synthetic six-scenario
program. It requires mode, a never-existing child directory and its exact
ordinary parent below D:\build_cache; it changes only newly created fixture
content. An unknown native owner is retained rather than silently retried.
Original native review1436 preserves its old source and actual native results;
this relocated crate and guarded fixture need independent current evidence.

Product capture/ancestor policy, approval, original shared accounting/clock,
worker lifecycle, actual overflow/close-failure and formal UI remain required.
No rename mutation, implicit enumeration, resynchronization or replay is added.
