# Morrow Windows 阶段 Demo 02

基线 0.1.9-test.10。独立 Flutter Windows 界面、真实 Rust 宿主、三个不同用途的 C／C++／Rust Wasm 插件。解压完整目录，双击 `MorrowStageDemo.exe`。

## 三种工具

| 工具 | 可以实际操作的功能 |
| --- | --- |
| Rust 文字工坊 | 粘贴文字、去除行首尾空白、移除空行、合并为一段、整理回填、清空；实时统计非空白 Unicode 标量数、非空行数和 UTF-8 字节数 |
| C 单位换算 | 摄氏／华氏、米／英尺双向换算，示例数值与重置；保留三位小数，非法输入可直接改正 |
| C++ 清单助手 | 从多行文字生成前 8 个任务，逐项勾选、只预览未完成项、按名称排序、清除已完成、恢复示例及完成比例 |

文字工坊支持 2048 UTF-8 字节；换算输入最多 32 字节，普通十进制数绝对值不超过 1,000,000；清单输入最多 1024 字节。清单编辑会重置勾选，排序保留每项勾选并按 UTF-8 字节序比较；排序或清除会将输入整理为展示的前 8 项，超出的输入不会保留。长任务标签会截短显示，预览保留完整文字。

切换工具时同时改变名称、主题色、图标和结果布局，并淡入新工具。顶部切换明暗主题和窄屏；结果面板可复制插件返回文字或重新开始当前工具。小窗口和清单工作区可滚动。复制是用户主动触发的宿主剪贴板操作，不授予插件系统剪贴板访问能力。

## 会话与边界

全部整理、换算、清单操作及结果由各自语言的真实插件计算。Flutter 渲染插件控件和返回值，不在界面层重算结果。宿主先校验事件所属会话、修订、序号、控件动作、可用状态与文本预算，再把当前可信快照与事件交给包声明的处理器。

每个工具会话使用私有临时库，没有内容权限，不保存正式资料库。切换工具、重新开始或关闭窗口会丢弃会话数据。文字输入可以串行排队；有未确认输入时暂禁用按钮与开关，语义操作返回前暂停编辑，防止排序前的旧勾选错作用于新任务。连接失败终止会话，不自动重试。

Demo 内部的 `morrow.demo.update.v1` 是专用实验帧：小端 u32 文档字节数 + u32 保留零（维持 8 字节对齐）+ 当前 Cap’n Proto Document + Cap’n Proto Event，总长最多 65536 字节。快照由宿主提供；返回仍是独立校验的 UI Document。该帧不是新的公共 SDK 消息契约，不改变核心 UI schema 或已有示例。

C SDK 新增有所有权的 UI 文档读取接口，供 C/C++ 工具读取上次快照。插件安装管理、持久草稿、正式内容提交、完整审计和跨平台接入仍在建设；本展示不代表它们已经完成。

## 构建与证据

运行 `tool/build_stage_demo_windows.ps1`，生成 `dist/morrow-0.1.9-test.10-demo2-windows.zip`，不会覆盖 Demo 01。依赖现有 Flutter Windows、Rust、LLVM、WASI sysroot 和 MSVC 可再发行运行库。

脚本编译三种真实模块、不可变包、优化版宿主与 Flutter Release，运行真实子进程的插件测试和控件测试，再由实际 Windows Release 自检生成原始截图。`--showcase=<绝对目录>` 会测试文字整理、换算错误恢复、清单排序／勾选等结果，截图后退出。正常启动供手动操作。

随包包含五张原始截图、运行验证文本、许可信息与 SHA256SUMS。截图来自真实 Release 的应用内容，不含系统边框；控件测试模拟输入与点击，复制测试检查发往平台的内容，不声称完成真实输入法或物理鼠标验收。
