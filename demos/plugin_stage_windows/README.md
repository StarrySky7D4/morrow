# Morrow Windows 阶段 Demo

基线 0.1.9-test.10。独立 Flutter 桌面入口搭配真实 Rust 宿主与 C／C++／Rust Wasm 插件包，展示界面生成、标题编辑往返、主机校验、明暗主题与窄屏布局。使用私有临时数据库，示例不请求内容权限。

## 运行

解压完整发布包，双击 `MorrowStageDemo.exe`。选择语言后编辑标题，右侧预览会在插件回应后更新；右上角切换明暗主题和窄屏预览，下方色点切换主题色。窄屏可纵向滚动。

当前示例只实现标题编辑；置顶和应用按钮禁用，作为组件外观预览。插件安装管理、持久草稿、正式内容保存和 Web 在线插件会话不在本 Demo 中。输入在切换插件或关闭窗口后重置，标题应保持简短。

## 构建与验证

仓库根目录运行 `tool/build_stage_demo_windows.ps1`。依赖现有 Flutter Windows、Rust、LLVM、WASI sysroot 和 MSVC 可再发行运行库。脚本构建真实模块，生成不可变包，编译优化版宿主与 Flutter Release，运行带真实子进程的控件测试，再由实际 Release 自检输出原始 PNG，完成打包与 SHA-256。

`--showcase=<绝对目录>` 是展示验收入口：实际 Windows Release 分别打开三种插件会话，调用相同交互桥检查标题返回，捕获真实应用内容并退出。它不模拟物理鼠标或输入法；控件测试独立覆盖真实 TextField 输入、语言切换、连续输入和窄屏。正常启动为手动交互模式。

## 演示边界

每种语言使用独立子进程和一次可信视图会话。通过 stdin/stdout 传输有界二进制帧：请求含已编码 UI Event，响应含修订及原始 Cap’n Proto Document；固定帧头仅用于本地 Demo 传输，不是锚定的公共插件 ABI。正文和事件仍按 UI v1 校验，UInt64 不转浮点。事件由宿主 Session 接纳后进入不可变包绑定的纯任务；更新独立解码再交 Flutter。

宿主对所有返回快照统一禁用未实现动作并重新验证文档。该策略也进入宿主 Session，不能从被禁用按钮绕过事件检查。调用方串行派发，较早回应不会覆盖新的本地输入；失败终止当前会话，不自动重试。切换会话关闭旧进程，失效回调丢弃。退出回收临时库，不操作正式用户数据。

本 Demo 是阶段展示的专用接入层，不代表主应用已经完成包 UI 注册、权限界面、稳定 IPC、持久在线会话、完整审计或跨平台验收。
