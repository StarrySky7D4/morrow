Windows qualification framework candidate

The manifest pins Flutter 3.50.0 stable, Dart 3.14.0, the Windows x64 debug
engine and the 735 files used to assemble the isolated framework package.
Flutter is licensed under the BSD license reproduced in LICENSE.

Flutter 3.50.0 includes the traversal grafting and hit-test fixes from upstream
PRs 186118 and 186826. The accompanying patch preserves distinct non-null
traversal anchors, publishes the reachable native semantics tree and resends
subtrees when they reappear, change parent or reuse a node ID. The archived
3.44.0 product and accessibility evidence belongs to that earlier candidate.

Run tool/prepare_windows_flutter_framework.py with the SDK and a freshly
resolved project package_config.json. Use the emitted .dart_tool/package_config.json
with flutter test --packages or flutter build windows --packages. On Windows,
put each framework preparation under D:/build_cache in a new directory.
