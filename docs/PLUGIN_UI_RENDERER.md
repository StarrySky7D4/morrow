# Flutter 插件表单渲染与接入边界

应用基线 0.1.9-test.10；独立 UI 契约 v1。`packages/morrow_plugin_ui` 新增基础宿主控件渲染，沿用 [UI 消息协议](PLUGIN_UI_PROTOCOL.md) 的有限节点集合。SDK 语言边界保持 C／C++／Rust，Flutter 是可信宿主实现语言，第三方无需编写 Dart Widget。

## 分层

`UiDocument.decode` 验证 Cap’n Proto 契约和消息限额，生成不可变节点；`UiDocumentModel` 与 `UiNode` 提供不依赖二进制传输的类型化值及相同树形／字段预算检查。后者本身不证明消息来源或授权，不能替代边界解码。

`PluginForm(document, viewIdentity, onIntent)` 渲染宿主控件。界面实例身份来自可信接入层；不能从插件节点或动作 ID 派生权限。渲染器只产生 `UiIntent`，由后续接入层关联视图、generation、revision 和连续 serial，再交 Rust Session 检查，绑定实际插件连接并形成受限任务。接受 UI 事件不意味着内容已提交。

当前控件验证器使用测试适配器完成一次“真实输入 → UiIntent → UiEvent → Rust 接纳”，生产确认、序号分配、队列背压与任务调度没有在渲染包中假实现。

## 界面行为

| 范围 | 已实现行为 |
| --- | --- |
| 行列 | 有界 Column、Wrap；行按可用宽度分配槽位，窄屏折行；整个表单纵向滚动 |
| 文本 | normal／muted／emphasis 映射 onSurface／onSurfaceVariant／primary；普通文字软换行 |
| 操作 | 宿主 FilledButton、TextField、SwitchListTile，继承 Theme 和本地化 |
| 透明与颜色 | 根 Material 透明；不新增模糊或覆盖宿主玻璃背景；字段及按钮表面由宿主 Theme 控制 |
| 交互边界 | 禁用、删除、换代和卸载后的旧回调丢弃；当前节点动作和输入预算再次检查 |
| 无障碍 | 使用 Flutter 控件语义与焦点遍历；已有语义标签检查，未完成读屏实测 |

模型限制最多 128 节点、深度 8，并不等于已完成生产帧率／洪泛压力测试。宿主需提供有限横向约束。Markdown、选择器、列表表格、资源租约及专业绘制仍是后续节点能力。

## 输入与快照

文本、光标、选区和未确认的输入法组合留在 Flutter。组合中的文本可暂时超过字段预算，但不会发出事件；确认时按 UTF-8 字节和控制字符校验，不合法则恢复最近有效输入，不在 Unicode 中间截断。

主题、宽度与相同字段值的完整快照更新保留本地草稿、选区和焦点。显式改变文本或字节上限会应用宿主值，且不会发出虚假的编辑事件；显式开关值更新同样覆盖本地值。新 viewIdentity 更换全部局部控件状态。宿主如需冲突提示、持久草稿或恢复，必须在替换视图前走核心策略，不能把本地缓冲区当作保存成功。当前没有“强制重置到相同快照值”的单独协议。

## Web 路径与证据

普通 Dart→JS 无法精确表达旧 Cap’n Proto Dart 生成器中的部分 64 位反射字面量。因此渲染器仅导入 `ui_models.dart`；原生和 Dart/Wasm 的 `ui.dart` 二进制编解码保持独立，并已重新验证完整 UInt64。

Web 预览模型由工具读取独立 Rust 原字节后离线生成，复现脚本校验生成文件没有漂移。真实 Chrome 加载 Flutter JS／CanvasKit 控件并产生用户意图；Dart/Wasm 探针独立验证二进制链。两类证据不能合并宣称主应用已经建立 JS 控件到 Wasm 核心的动态通路。

本机 Flutter 3.44 的 Chrome 单元测试服务器对 CanvasKit 路径返回 404，故使用构建后的静态页面与仓库 CDP 验证器，未修改全局 Flutter SDK。测试页面加载本机字体，避免外部默认字体服务不可用影响测量；字体仅通过本地服务器提供，不作为产品资产提交。
