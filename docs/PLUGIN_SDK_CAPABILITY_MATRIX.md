## 26项能力矩阵（当前源码校正）


S013原审计为只读源码检查；其JSON和报告保留当轮证据。本表依据后续C02–C07已记录的接口增量校正当前分类，本文同步未运行新测试。测试源码、编译或本地codec结果仍不能代替对应运行／平台／产品资格。

当前SDK能支持有界内容操作、纯Transform、批准slot纯依赖调用和六节点表单；有界HTTP/服务、Create/Delete是分别版本化的实验扩展。公开实验 channel 已支持 host 显式交付的有限本地 bytes/events；已有显式批准的实验POST SSE／WS来源和有限changes metadata guest；完整Responses产品流、Cloud同步、Codex常规exec/session、大对象与专业UI仍缺公共SDK闭包。宿主stream/监督/私有Workbench协议不能填成公开三语言接口。

## 冻结判断

未发现未来共用能力必然要求破坏现有Wasm ABI的证据。纯业务格式适配可复用既有Transform；新的共用能力可以沿当前独立opt-in/profile机制演进，但仍要实现其真实授权、数据、生命周期与版本路由。Package静态feature白名单不是一般运行时能力协商。旧schema精确SHA是门禁：即使新增字段或改注释，也不能直接覆盖旧冻结schema/原件。

冻结是否被未来功能阻塞取决于明确宣称范围：若仅冻结现有有界Windows guest profile，未来缺功能本身不必阻止；若宣称开发者现在能完成本矩阵完整Codex/Cloud/流式网络，这些缺口就是实质阻塞，不能用样例数量或重新编译旧包掩盖。本审计不把范围自动缩小，最终范围及本轮兼容回归由父线程确定。
