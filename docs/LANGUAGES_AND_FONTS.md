# 语言扩展与自定义字体

## 增加语言

语言清单由 `packages/morrow_i18n/languages.json` 管理，包含语言代码、自称、源语言和回退语言。当前保留中文、英语、俄语、法语、德语、西班牙语、日语、韩语和葡萄牙语。

以意大利语为例：

1. 在清单的 `languages` 中增加 `{"code": "it", "nativeName": "Italiano"}`。
2. 添加 `packages/morrow_i18n/l10n/parts/common.it.arb`，以及根目录 `l10n/parts/` 下的 `main.it.arb`、`visual.it.arb`、`plugins.it.arb`、`imports.it.arb`、`recovery.it.arb`。
3. 保持全部消息键、占位符名称和类型与源语言一致，翻译对应文案及 ICU 复数表达式。
4. 从仓库根目录执行 `python tool/build_i18n.py --generate`，再执行 `python tool/build_i18n.py --check` 和 `python -m unittest tool.tests.test_i18n_catalog`。
5. 重新构建应用和原生宿主。语言菜单、Dart 语言资源和 Rust 可保存语言列表均由清单生成。

不要手改生成的 ARB、Dart 文件、Rust 语言列表、`l10n.yaml` 或 `.mlang` 文件。当前支持两至三个小写字母的语言代码；地区和文字变体尚未接入。新增语言还须有 Flutter Material／Widgets／Cupertino 对应的本地化委托。

本轮提供的是外置开发配置和重新构建流程，不包含应用内安装任意语言包。现有 `.mlang` 的摘要校验和编译消息绑定继续保留。

## 自定义字体

入口：**设置 → 空间外观 → 字体设置**。

- 输入本机字体族名称并应用，例如 `Arial` 或 `Microsoft YaHei`。
- 导入单个 `.ttf` 或 `.otf` 字体文件，最大 20 MiB。导入成功后立即应用，并显示多语言预览。
- 使用“恢复默认”恢复原字体；切换不重建工作台身份，编辑文字、选区和输入法组合状态保留。
- 常规界面和标题栏继承字体设置，代码展示继续使用等宽字体。文件缺少某些字符或指定系统字体不可用时，按平台字体回退规则显示。

字体选择随内容库保存，字体文件保存在本机应用支持目录的 `fonts` 中；Web 使用当前站点的 IndexedDB，不上传文件。导入后不再依赖原文件路径。字体文件使用内容摘要命名，恢复时重新核对摘要及文件结构。

字体文件不随内容库跨设备迁移。若文件缺失、损坏或浏览器存储被清理，应用恢复默认显示并提示重新导入，保留原选择元数据。重置字体不会自动删除本地文件，避免其他内容库引用失效。

运行期字体不能逐个从 Flutter 引擎卸载，因此每次启动最多注册 8 个导入字体，累计源文件最多 64 MiB；达到限额可重启后再切换。这是源文件预算，不是完整的原生/GPU 内存计量。当前不支持 `.ttc`、`.woff`、字体家族多字重组合或自动枚举系统字体。

原生字体元数据由 Rust 宿主通过现有事务、修订和操作身份保存，不修改插件 SDK 契约；私有宿主协议已更新，应用须使用本次配套宿主。
