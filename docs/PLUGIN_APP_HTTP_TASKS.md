# 主应用 HTTP 任务接线

本入口将已保存端点连接到独立准入的真实 Rust/Wasm 插件任务。它属于实验性 IO；通用任务界面、恢复核对和三语言 SDK 的完整能力仍按原看板推进。

## 明确的输入契约

`plugins/http_forward` 是零依赖 Rust guest，声明 `morrow.http.forward.v1`。宿主将一份固定 IO Request 原帧作为输入；guest 恰好转发一次并原样交付响应。不是所有声明 `http-request` 的插件都接受这个输入。宿主检查明确的 profile，实际网络路由还核对 guest 请求与宿主生成帧逐字节一致及调用序号为零，防止恶意插件替换方法、路径、正文或操作身份。声明 profile 不会绕过这些运行期检查。

可信 UI 提交端点引用／修订、包摘要／Registry 修订、32 字节非零提交身份、方法、相对路径、普通头部、有限正文与任务期限。没有可提交的 origin、证书、明文凭据或自行授予的能力。宿主从原 Store 读取配置与授权租约，再在 `start_io` 的真实实例和 IoBinding 上批准并解析系统凭据；不创建第二份数据库。

网络 runtime 随路由对象移入任务线程，与原 Storage 一起存活到实际回收。方法、地址政策、请求头、请求／响应预算沿用已有网络传输；任务上限再与插件声明预算相交，每任务最多一次 IO。任务期限最多 30 秒且不超过插件声明。

## 私有控制协议

| 动作 | 语义 |
| --- | --- |
| httpStart | 显式新请求，返回任务状态及关联身份 |
| ioStatus | 不需要旧 TaskKey，读取当前状态以核对丢失的启动回执 |
| ioPoll | 按精确 TaskKey 查询；Ready 仍须经过最终交付授权 |
| ioRead | 消费一次受控结果，返回 HTTP 字节与执行／取消／未知状态 |
| ioCancel | 请求停止并撤销交付；不是回滚或线程已经退出 |
| ioRepair | 只恢复原实例清理／原存储封存，不执行网络任务 |
| ioAcknowledge | 实际回收且恢复完成后，明确放弃已结束任务的剩余状态 |

任务控制在内容库 Busy 时仍可响应。结果只传一份 HTTP 正文和头部，不重复包装 guest 输出；HTTP 4xx/5xx 仍保留真实远端状态，执行失败、取消和 OutcomeUnknown 分别表示。读取是消费操作：回执丢失后不得重跑网络请求来补回界面数据。

提交身份编码为持久 IO operation ID。同一宿主进程保留最多 512 个已进入准入尝试的身份，包含失败尝试；确认任务不删除该集合，满额拒绝后续尝试，不通过淘汰允许旧身份重放。启动回执丢失后只读 ioStatus 核对。进程重启不恢复 TaskKey 或活动授权；跨进程未知效果须通过原持久意图／证据核对，不能通过更换提交身份自动重试。

## 关闭

CLI 正常 EOF、显式终止、半截消息、读取失败、输出写入或 flush 失败均先请求停止，再等待原线程真实归还存储。Busy 只表示仍在等待；不以固定超时宣称完成。清理或封存失败保留错误，不隐式重试网络操作。

Dart 关闭拒绝新请求、等待已排队请求、关闭输入并等待实际进程退出；不再五秒后强杀。关闭尚未完成时调用方应保持等待状态。系统强制结束进程仍可能留下需要持久证据核对的外部效果。
