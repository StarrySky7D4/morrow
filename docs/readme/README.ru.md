# Morrow · 明隙

[简体中文（默认）](../../README.md) · [English](../../docs/readme/README.en.md) · **Русский** · [Français](../../docs/readme/README.fr.md) · [Deutsch](../../docs/readme/README.de.md) · [Español](../../docs/readme/README.es.md) · [日本語](../../docs/readme/README.ja.md) · [한국어](../../docs/readme/README.ko.md) · [Português](../../docs/readme/README.pt.md)

Оставьте немного места для завтрашних идей.

Morrow (明隙) — локальное рабочее пространство для идей на основе карточек, развивающееся в сторону кроссплатформенной системы плагинов. Прежнее название — daemon, имя пакета — `morrow_studio`. В Windows интерфейс построен на Flutter, а логика работает в Rust-хосте с изолированными Wasm-плагинами. Web и Android пока используют прежнюю реализацию; поддержка системы плагинов на всех платформах ещё не подтверждена.

## Загрузка и совместимость

Текущая версия: **0.1.9-test.55+59** — **тестовая сборка для Windows x64**, не стабильный выпуск. Скачайте ZIP приложения, ZIP соответствующих исходников и список SHA-256. Полностью распакуйте архив и запустите `morrow_studio.exe`, сохранив DLL, хост, каталоги `data`, `plugins` и файлы лицензий.

[Скачать test.55](https://github.com/StarrySky7D4/morrow/releases/tag/v0.1.9-test.55) · [Совместимая версия test.1](https://github.com/StarrySky7D4/morrow/releases/tag/v0.1.9-test.1)

`test.1` — последняя тестовая версия `0.1.x`, совместимая с исходными типами данных. Последующие версии test сопровождают переписывание и могут нарушать совместимость. Выпуск `0.2.0` последует после стабилизации архитектуры, модели данных и приёмки. Данные test.1 не импортируются и не перезаписываются автоматически. Перед обновлением сохраните библиотеку и исходный файл защиты. Защита привязана к пользователю Windows; копирования одной базы недостаточно для переноса между учётными записями.

## Возможности

- Карточки: идеи, проекты, эксперименты, избранное, поиск, списки задач и отмена удаления; редактор Markdown с предпросмотром и отдельные копии вложений.
- Захват содержимого: текст, снимки экрана, файлы, форматированный текст и таблицы Office. Сложные или закрытые форматы могут сохраняться как предпросмотр или вложение; точное воспроизведение оформления не гарантируется.
- Оформление: матовое, сверхпрозрачное и жидкое стекло; стандартный, однотонный, текстурный и прозрачный холст; цветовой круг темы, отдельные настройки карточек и компонентов, уменьшение анимации.
- Медиа: фоны из изображений, GIF и видео, локальная музыка, тексты песен и плавающие подсказки. Поддержка форматов зависит от платформы и декодера. Прозрачность Web показывает фон страницы, а не рабочий стол.
- Макет и языки: адаптивное содержимое и отдельные страницы настроек; китайский, английский, русский, французский, немецкий, испанский, японский, корейский и португальский.
- Защита в Windows: единое хранилище Rust, запечатывание записей аудита, снимки библиотеки, резервирование и восстановление исходной идентичности, ограничение её одновременного использования.

## Обновление и проверка

test.55 добавляет семь стилей оформления и настройку глубины, улучшает анимацию элементов управления и расстояния между компонентами, исправляет сохранение настроек и применение шрифтов, улучшает безопасное закрытие в фоновом режиме и закладывает основу восстановления черновиков. Автосохранение в основном интерфейсе пока не завершено.

### Предыдущая оптимизация и проверка test.54

test.54 устраняет повторные полные проверки при открытии библиотеки, ограниченно распараллеливает декодирование свидетельств и повторно использует проверенные размеры и дайджесты архивов в одной транзакции. Каждое открытие по-прежнему выполняет полную проверку. Формат хранилища и встроенный плагин не изменены; результаты проверки не сохраняются между запусками.

Последнюю оптимизацию чтения сравнили с предыдущей параллельной версией: по четыре чередующихся запуска. На одной машине с копией библиотеки около 100 МБ медиана снятия загрузочного экрана снизилась с 2.222 до 1.299 с от входа в Dart. Регистрация копии может прогревать файловый кэш: это не гарантия холодного старта с очищенным кэшем. Пройдено 568 тестов Core, 97 Audit и 2 интеграционных теста с реальным хостом; один ранее существовавший тест Core пропущен. Условия приведены в [примечаниях к test.54](../../reports/0.1.9-test.54-release.md).

## Запуск из исходников

Нужны Flutter 3.44 / Dart 3.12 или совместимые версии. Для Windows также требуются инструменты Visual Studio для C++, Windows SDK, Rust и компилятор Cap’n Proto в PATH.

Полная сборка Windows Rust, интеграционные проверки и упаковка:

```powershell
flutter pub get
rustup target add wasm32-unknown-unknown
pwsh -File tool/build_rust_workbench_windows.ps1
```

Готовые артефакты не перезаписываются: используйте новую версию или новый выходной каталог. `-RefreshArtifact` больше не разрешает замену. Распространяйте весь каталог приложения. Сборка Windows не подтверждает готовность Web или Android; их границы проверки описаны отдельно.

Разработка и базовые проверки:

```powershell
flutter run -d windows
flutter run -d chrome
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

## Архитектура, SDK и дальнейшие задачи

Целевая архитектура: интерфейс Flutter/Dart, переносимое ядро Rust и заменяемые среды выполнения плагинов. Во время работы используются фиксированные контракты, для хранения и собственных обменов — Protobuf + LZ4. SDK для C/C++/Rust и декларативный интерфейс плагинов развиваются. Плагины TS/JS не поддерживаются; динамические плагины Dart не требуются.

Полный SDK ещё не зафиксирован. Подключены управляемые HTTP/HTTPS-запросы, ограниченные API-узлы и управление TLS-идентичностями. Остаются сверка результатов Unknown после перезапуска, полная файловая система, IO SDK на трёх языках и проверка других платформ. Открытие всё ещё сканирует всю историю; полный конвейер чтения и вычислений, разделение истории на уровни и автоматическая очистка не реализованы.
