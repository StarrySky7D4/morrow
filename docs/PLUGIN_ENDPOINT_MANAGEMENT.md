# 主应用持久端点管理

插件库提供独立的端点面板，通过原生 Workbench 的私有协议读写原 Store v20。它管理持久批准；保存不会启用插件、建立网络连接、解密凭据或创建活动授权。应用版本仍为 `0.1.9-test.52+56`。

## 配置与权限

用户选择当前插件、精确 origin、公开 HTTPS／本机 HTTP／本机 HTTPS、允许的方法、可选凭据引用、有效期与额度。高级参数包括请求／响应／头／协议帧字节上限、并发数和超时。HTTPS 可选择单份 DER 信任根，最大 32768 字节；界面做结构检查，宿主复用实际传输层的证书解析，不接受 PEM。HTTP 不展示证书选择入口。

保存绑定当前 Registry 修订及选中原包摘要，重新校验原包、声明与已批准 `http-request`；引用凭据还需声明和批准 `credential-use`。插件可以尚未启用。替换绑定原引用、修订与固定插件 ID，明确使用当前包摘要；冲突要求重新读取，不自动重发。

有效期为保存时起 1–30 天；带凭据的端点不能超过凭据到期时间，系统不会偷偷缩短或延长期限。因此，较早创建的同为 30 天凭据通常无法覆盖稍后创建的 30 天端点，需选择更短的端点期限。保存只检查凭据记录类型、提供者、停用及时间状态，不调用 DPAPI 解密；实际任务仍需在原实例准入后重新验证并解析秘密。

停用仅依赖端点引用及原记录修订，不依赖插件包仍存在、类别仍获批准或凭据仍有效。已停用且修订匹配时保持幂等；过期修订不能利用幂等绕过冲突检查。成功修改复用原 Store CAS 与授权撤销协调器。

## 分页、协议与界面

私有 `endpointPage`／`endpointSave`／`endpointDisable` 为追加动作，完整传递政策字段。读取在共享出站表每页最多取两条再过滤端点；仅含凭据的空页仍保留游标。原表快照与严格递增引用阻止混合读取；最多检查 512 条原记录。两份最大 DER 政策的响应仍在 128 KiB 私有帧限额内，回归逐字节核对证书内容。

历史政策按持久记录格式读取，不因当前传输层的方法或证书规则而失去列表和停用入口。新建／替换仍须通过当前完整传输校验。宿主与 Dart 必须同步构建以匹配新的私有 schema 摘要；冻结 C／C++／Rust guest SDK 及原包不变。

面板复用主题样式与中英文资源，320 像素布局有 widget 回归。工作台、注册表、包摘要、表单和证书选择使用会话代数隔离迟到结果；写入结果未知时只提示重新读取。凭据列表失败仍允许读取和停用已有端点。Web 没有此原生后端时不显示该面板，Web 编译通过不代表 Web 凭据或网络 IO 可用。
