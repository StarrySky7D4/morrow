# 持久入站认证与发布批准

本轮是原生服务底座的限定实现。应用仍为 `0.1.9-test.52+56`，没有接入主应用发布界面，也没有宣布新 SDK 稳定。验证入口见 [报告](../reports/service-authority-2026-09-20.md)。

后续已接入的Workbench Rust配置/令牌/发布批准管理见[管理合同](PLUGIN_SERVICE_MANAGEMENT.md)；私有消息、Flutter页面与工作台监听生命周期仍待实现。

## 原 Store 数据

Store v19 在原数据库增加 `service_authorities` 和单例 `service_authority_identity`。v18→v19 原子迁移保留原配置、内容与证据；此前版本无法打开升级后的数据库。配置、认证和批准使用规范 Protobuf＋LZ4，没有独立权限数据库。

批准记录使用非零32字节引用和逐次修订 CAS，最多512条、单条原文32KiB，与配置、事件和证据共享逻辑字节额度。身份元数据是固定大小的存储协调开销。记录创建时间和到期时间为 UTC 毫秒，期限最多30天；以新修订禁用，不提供删除复用身份的接口。

- Authentication 保存主体和 SHA-256 bearer 验证摘要，不保存原始令牌。宿主必须另行生成并交付高熵 bearer；非零摘要不证明令牌强度。摘要不具备向其他 API 发送认证的能力。
- Publication 固定配置 ID、完整配置容器摘要、规范监听地址、是否使用 TLS、方法、业务路径及可选的独立查询路径。非回环地址强制 TLS。证书及私钥仍由宿主独立提供。
- 引用类型和关联主体／配置不能在原引用下替换。认证摘要可在新修订中轮换；配置变更使旧发布批准的摘要失配，需要重新批准。

## 恢复和运行检查

`ResolvedService::resolve` 从原 Store 固定配置和批准引用，检查当前时间、禁用标记、配置摘要及全部认证记录。`issue` 继续核对原 Store 的不透明租约、实际 Manager／IoBinding、当前包与处理器，并用现有逐对象内容授权生成最大范围。保存的数据不能代替这些当前批准。

`ServiceHost::bind_configured` 使用批准内的地址、TLS 模式、方法和路由；调用者不能覆盖这些值。原 worker 执行实际 guest，原数据库保存请求历史。认证后仍检查服务范围和精确内容权限；查询继承相同检查，不触发重发。

所有已解析的服务、监听与 Principal 共用撤销及绝对期限检查。每个解析实例维护 UTC 高水位和单调时钟截止时间，时间倒退或到期永久使该实例失效；克隆不续期。当前保守策略使用所有主体和发布批准的最早到期时间，一项失效即停用整个发布。Principal 另有不超过24小时的单次运行上限。跨进程可信时间高水位尚未实现，重启仍依赖可信 UTC 来源。

## 原拥有者与更新

原生 Store 用数据库内的随机稳定 ID 在固定用户目录选择一个独立文件锁。Windows 位于 `%LOCALAPPDATA%/Morrow/service-authority-locks`，Unix 位于 XDG 状态目录或用户 `.local/state/morrow/service-authority-locks`。该目录与数据库元数据属于可信用户配置；机制约束合作宿主，不防护拥有同一系统账号的人任意替换文件。

恢复活动批准时原 Store 持有锁直至销毁。普通、独占和显式原生 VFS 的配置／批准写入均参与协调；相同 ID 的数据库副本也保守互斥。独立 SQLite 内容事务、快照读取不使用这把授权锁。未知原生存储拒绝伪装成内存后端；内存与 Web 可以使用数据编解码和存储接口，但不能恢复活动原生服务批准。

同一 Store 的配置或批准写入在通过 CAS 和身份校验后、实际修改前撤销所有已解析服务。之后即使容量不足、回滚或提交结果不确定，也不恢复旧租约。直接 Store 调用若 CAS 提前冲突，不撤销已有租约。

运行期间通过 `IoWorker::update_service` 或 `ServiceHost::update_service` 将修改排到原 worker。入队接受后立即撤销已解析服务，实际 CAS 仍由原 Store 串行执行；因此入队后的 CAS 冲突也不会恢复旧权限。队列满或停止时拒绝入队。回执区分提交结果与接受状态；未取得回执不是回滚证明，不能盲目重发。改动后须重新解析并签发新实际授权，当前不提供热替换。

原 Store 销毁先使租约失效，再释放授权锁。撤销在请求、导入、效果、Ready/read 和网络交付边界检查，不能撤回已交付字节或取消已经发生的外部副作用。
