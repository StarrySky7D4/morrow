# test.1 功能迁移与 test.32 开发验收记录

日期：2026-09-13。对照基线为本地 `v0.1.9-test.1`。当前开发版本 `0.1.9-test.41+46`，通用运行期协议 v7，实验 C ABI v1。首个接入平台为 Windows；不表示旧数据自动兼容或全平台重构完成。

## 本轮实现

Windows 主入口使用 `workbench_host`、不可变 `.morrowplugin` 包和真实 Rust Wasm guest。四个业务处理器负责工作台内容、媒体／外观策略、偏好和捕捉转换；另有两个纯 UI 处理器负责在线文字工具。Flutter 保留界面、输入、平台剪贴板、媒体解码及文件选择；插件没有原生文件路径访问能力。正式卡片以独立事务写入 Rust 核心，配置使用单独的类型化卡片，均为 Protobuf＋LZ4，不再把 Windows 的整份灵感列表写入 shared_preferences。

通用插件底座现有七类内容命令：重命名、摘要、操作查询、附件读取，加上本轮正文创建、编辑和分段读取。三种语言共用权限、修订、操作去重和回复关联规则。正文编辑保留核心外层未知字段与附件引用；第一方宿主额外使用授权后的附件原子提交入口。通用集合权限、附件导入授权和大正文写入会话还未开放给第三方 guest。

## 透明画布与组件材质

透明画布提供磨砂范围 0–40、不透明度 0–100%、独立颜色罗盘。界面滑条显示百分比。染色在 Flutter 透明画布内合成，不修改文字或整个窗口的不透明度。磨砂为零时关闭原生背景视觉；液体玻璃与四类画布仍独立组合。

Windows 的模糊改为独立的背景画布窗口，使用无重定向的合成表面、HostBackdropBrush 与 GaussianBlur，位于 Flutter 主窗口后方；主窗口维持原有逐像素透明。画布范围包含标题栏背景，并同步主窗口位置、尺寸、圆角、隐藏和关闭。模糊归零时将背景层淡出到完全透明，关闭窗口时释放。低强度范围平滑混入背景磨砂，模糊和混入强度均使用 280ms 过渡。染色只在 Flutter 画布上绘制，0 不透明度为完全透明；不设置主窗口总透明度，也不把前景控件作为模糊输入。背景效果不使用截图作为材质来源。

已通过受控像素验证：自有红蓝色块背景在 0 模糊 / 0 不透明度时原样透出，12 模糊使色块边界融合，标题栏背景同步模糊、不透明前景保持不变；50% 染色改变画布颜色，归零后原样恢复。检查只采样测试程序自身覆盖的固定位置，遇到其他窗口遮挡即拒绝；不是对任意桌面截图的分析。普通运行不会启动该场景。

组件默认继承主题。入口为「空间外观 → 组件与卡片 · 独立设置」。每个组件和每张内容卡片都有单独的页面、开关、磨砂、不透明度和罗盘。内容卡片以稳定 ID 关联，在不同页面呈现时保持同一设置，其他卡片不受影响。历史全局材质参数仅用于新建独立配置的初值，不再覆盖所有组件。关闭开关保留该项参数，取消编辑不保存；应用后通过 Rust 偏好协议与核心事务保存。编辑弹窗和高对比模式保留可读性下限。

## 容量与下一阶段

通用正文写入暂为每次 32 KiB；工作台业务消息仍为 64 KiB。整份偏好提升到 4 MiB，通过 32 KiB 有序片段传输，完整校验 SHA-256 后才进入原子保存；插件按页校验，每首歌曲（含歌词、封面来源等）的独立记录仍须不超过 64 KiB，歌词本身上限 48 KiB。超限或失败保留旧配置。捕捉树上限 1024 节点；这些容量尚不能宣称与 test.1 全场景等价。核心待封存事件默认最多 1024 条或 64 MiB；test.19 Windows 工作台在达到 64 条或 8 MiB 时，于下一次修改前自动封存并确认队列。连续 1100 次创建已验证不会堆满旧队列，但这不代表历史存储容量无限，磁盘或维护失败仍会阻止后续写入。原始附件总库容量沿用核心限制。

下一阶段优先：大正文的分段写入与偏好独立记录保存、事件确认与历史保留策略、草稿恢复、受范围约束的集合与附件导入 API、安装升级/卸载生命周期、完整 Office 实际粘贴和多格式媒体验收，然后推进其他平台。现有已验证能力与这些待办分开记录，不将本轮标记为全部插件系统完成。


审计底座前置进展：`core` 与 `audit/` test.16 已提供签名提交段、事务归档、核心原子队列确认与离线核验，见 [模块边界](../audit/README.md)。test.19 默认 Windows 工作台已通过受系统账户保护的 Session 接入分批封存，保留原始操作与历史附件，仅原子确认已封存队列。密钥缺失时恢复原文件，不能自动补建；详见 [test.19 记录](../reports/test.19-workbench-audit.md)。

## test.25 批准、启停与在线工具
